# Bongo Player 0.6.0 Part 1 (Foundation) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Bongo Player a settings screen (key `o`), NL/EN/DE texts everywhere, adult content hidden behind a PIN, and configurable news rules, without slowing anything down.

**Architecture:** Pure logic lands in small new modules (`i18n.rs`, `settings.rs`, `pin.rs`, `news.rs`, `redact.rs`), each unit-tested. The catalog becomes the single place that hides adult content. `settings_ui.rs` draws the overlay and returns actions that `app.rs` carries out, so `app.rs` grows as little as possible. Preferences live in `settings.json` next to the other config files; credentials stay in `BongoPlayer.ini`.

**Tech Stack:** Rust 2021, egui/eframe 0.27, tokio 1, reqwest 0.12, serde/serde_json, `ring` 0.17 (already in the dependency tree via rustls) for the PIN hash; wiremock and tempfile for tests; Python 3 + PowerShell + ffmpeg for the end-to-end harness.

**Spec:** `docs/superpowers/specs/2026-10-11-v060-fundament-design.md`

**Branch:** `feat/v060-fundament` (already created; the spec is committed there).

## Global Constraints

- Performance is the top constraint: no extra network requests at startup; `settings.json` is read once at startup and written only on a change; translations are static (`&'static str` for texts without values); the adult filter is one boolean check inside lists the catalog already builds; the settings overlay costs one `bool` check per frame while closed; nothing that searches or resolves runs every frame.
- No new crates except `ring = "0.17"`, which must not add a `[[package]]` to `Cargo.lock` (it is already compiled for rustls).
- Every user-visible text goes through `i18n.rs`. Allowed literals outside it: `APP_NAME`, the window title, brand-neutral tokens (`[TV]`, `LIVE`, `<< -30s`, `>> +30s`), key names (`F11`, `Shift+F`, `Esc`, `o`, …) and the trilingual language-screen title. Log messages stay English.
- Release builds use `panic = "abort"`: no `unwrap`/`expect` on anything from outside the program (files, network, user input).
- Credentials never reach a log line (user name and password in portal URLs are masked).
- PIN: exactly 4 digits; 3 wrong attempts in a row block PIN input for 30 s (in memory only). Forgotten PIN: cleared with the portal password.
- Settings key: `o`. Zap reversal also flips the mouse wheel, never the guide.
- Language preselected at first start from the Windows display language: Dutch → Nederlands, German → Deutsch, anything else → English.
- Connection test: 10 s timeout; outcomes "Verbonden: N zenders" / "Gebruiker of wachtwoord onjuist" (`user_info.auth` ≠ 1) / "Server niet bereikbaar" / "Geen geldige portal".
- TDD for every task: failing test first, then the code. One commit per task on `feat/v060-fundament`; each commit message ends with:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01WsPJfuisYwZ6smLPWrbS2D
  ```
- Never commit `BongoPlayer.ini`, `tv.bat` or any file holding the real portal credentials. Before each commit, the staged diff must not contain the real user name or password (see Task 3, `check-staged.sh`).
- Run commands from `rust/` unless a step says otherwise. Builds can fail with "os error 32" when Dropbox locks a file: simply run the command again.

## Deviations from the spec

- **Texts with values:** the spec suggests one function per such text (`fn preset_saved(lang, digit, name)`). The plan uses one table with numbered placeholders (`{0}`, `{1}`) that `tr()` fills. Same effect (each language orders the values itself), one place for all texts; a test checks that every translation keeps the same placeholders.
- **Portal error details:** the headline is translated ("portal ophalen mislukt"); the technical detail under it (the HTTP library's own message, masked) stays as the library writes it.

## Review Focus

Inputs the spec implies but no feature test would naturally hit. Each line names the task whose tests pin it.

- **Upgrading from 0.5.x** (ini, presets, favorites and `last_watched.json` present, no `settings.json`): the language screen appears once and everything else behaves as before. An old `last_watched.json` has no adult flag: it resumes once the catalog can tell it is no adult content (behind the language screen, so hardly noticed), and never resumes adult content. → Task 11 (defaults), Task 12 (e2e first start), Task 16 (old `last_watched.json`, unit test and e2e).
- **Hand-edited files** (`settings.json` with broken JSON, an unknown language code or one malformed news rule; `settings.json` or `BongoPlayer.ini` saved by Notepad as "UTF-8 with BOM"): no crash, only the bad field falls back to its default, the PIN survives, and a BOM changes nothing. → Task 4 (ini BOM), Task 11.
- **Credentials with `@` or `=` in the password**, written by the prompt or the settings screen and read back from the ini: the same credentials come out. → Task 4, Task 15.
- **Keys typed into text and PIN fields** (digits, `o`, `f`, space, letters) never trigger app hotkeys (presets, settings toggle, search, pause). → Task 12 (e2e), Task 16 (e2e PIN entry).
- **Zap order after unlocking or locking:** the zap list changes length; the next arrow press goes to the neighbour of the playing channel, not to whatever sits at the old index. The guide's cached channel list is rebuilt too. → Task 16.

`rust/e2e/mock_portal.py`:

```python
"""Mock Xtream portal for Bongo Player end-to-end tests.

    py -3 mock_portal.py PORT SEGDIR LOGFILE [MODE]

player_api.php   login check (user "tester", password "secret"), live / VOD /
                 series lists, EPG
/live/u/p/N.m3u8 302 to /edge/tokN/1: a fresh token per request, like the real
                 portal's edge redirect. The edge serves a sliding live
                 playlist of 4 s segments.
/timeshift/...   302 to /tsplay/vod.m3u8 (catch-up; generating it takes 2.5 s)
/seg/TOK/N.ts    the test segments made by make-segments.ps1

MODE: none (default) | once | always - the first (once) or every (always)
edge token answers 509 from its first reload on.

Environment:
  MOCK_CHANNELS=N    live channels "TEST 01" .. "TEST NN" (default 40)
  MOCK_VARIANTS=1    channel 05 also as "TEST 05 UHD" (105) and "TEST 05 FHD" (205)
  MOCK_ADULT=1       after TEST 02: "24/7 | ADULT A" (901, is_adult=1) and
                     "XXX | ADULT B" (902, is_adult=0, caught by the name rule);
                     VOD "Adult Film" (9001, is_adult=1) and "Gewone Film" (9002)
  MOCK_NEWS=1        "NL | NPO 1" (501) with archive twin "NL | NPO1 HD" (601,
                     tv_archive=1); the twin's EPG holds three past programmes:
                     NOS Journaal, NOS Jeugdjournaal, Tussen Kunst en Kitsch
  MOCK_DENY=105,...  streams refused to the account (HTTP 407)
  MOCK_BUSY_UNTIL=S  live requests answer 503 for the first S seconds
  MOCK_LATENCY=1     answer about as slowly as the real portal
"""
import base64
import http.server
import json
import os
import sys
import threading
import time
import urllib.parse

PORT, SEGDIR, LOG = int(sys.argv[1]), sys.argv[2], sys.argv[3]
MODE = sys.argv[4] if len(sys.argv) > 4 else "none"
ENV = os.environ.get
LATENCY = ENV("MOCK_LATENCY") == "1"
SEG_DUR = 4
NSEG = len([f for f in os.listdir(SEGDIR) if f.endswith(".ts")])
T0 = time.time()
lock = threading.Lock()
edge_hits, dead = {}, set()
state = {"tokens": 0, "failed_once": False}


def log(code, path):
    with lock, open(LOG, "a") as f:
        f.write(f"{time.time() - T0:7.2f}s  {code}  {path}\n")


def b64(s):
    return base64.b64encode(s.encode()).decode()


def live_streams():
    n = int(ENV("MOCK_CHANNELS", "40"))

    def ch(sid, name, archive=0, adult=0):
        return {"stream_id": sid, "name": name, "category_id": "1", "epg_channel_id": "",
                "tv_archive": archive, "is_adult": str(adult)}

    out = []
    for i in range(1, n + 1):
        out.append(ch(i, f"TEST {i:02d}"))
        if i == 2 and ENV("MOCK_ADULT") == "1":
            out += [ch(901, "24/7 | ADULT A", adult=1), ch(902, "XXX | ADULT B")]
    if ENV("MOCK_VARIANTS") == "1":
        out += [ch(105, "TEST 05 UHD"), ch(205, "TEST 05 FHD")]
    if ENV("MOCK_NEWS") == "1":
        out += [ch(501, "NL | NPO 1"), ch(601, "NL | NPO1 HD", archive=1)]
    return out


def vod_streams():
    if ENV("MOCK_ADULT") != "1":
        return []
    return [{"stream_id": 9001, "name": "Adult Film", "container_extension": "mp4", "is_adult": "1"},
            {"stream_id": 9002, "name": "Gewone Film", "container_extension": "mp4", "is_adult": "0"}]


def news_epg():
    now = int(time.time())
    progs = [("NOS Journaal", now - 7200, now - 6600),
             ("NOS Jeugdjournaal", now - 3600, now - 3000),
             ("Tussen Kunst en Kitsch", now - 2400, now + 1200)]
    fmt = lambda t: time.strftime("%Y-%m-%d %H:%M:%S", time.localtime(t))
    return [{"id": str(i), "epg_id": str(i), "title": b64(t), "lang": "", "start": fmt(s), "end": fmt(e),
             "description": b64(""), "channel_id": "npo1", "start_timestamp": str(s),
             "stop_timestamp": str(e), "now_playing": 0, "has_archive": 1}
            for i, (t, s, e) in enumerate(progs, 1)]


class Handler(http.server.BaseHTTPRequestHandler):
    protocol_version = "HTTP/1.1"

    def reply(self, code, body=b"", ctype="text/plain", headers=None):
        self.send_response(code)
        self.send_header("Content-Type", ctype)
        self.send_header("Content-Length", str(len(body)))
        for k, v in (headers or {}).items():
            self.send_header(k, v)
        self.end_headers()
        self.wfile.write(body)
        log(code, self.path)

    def json(self, obj):
        return self.reply(200, json.dumps(obj).encode(), "application/json")

    def do_GET(self):
        p = self.path
        if LATENCY:
            time.sleep(0.30 if p.startswith("/live/") else 0.12 if p.startswith("/edge/") else 0.05)
        if p.startswith("/player_api.php"):
            q = dict(urllib.parse.parse_qsl(urllib.parse.urlsplit(p).query))
            action = q.get("action")
            if action is None:
                ok = q.get("username") == "tester" and q.get("password") == "secret"
                return self.json({"user_info": {"auth": 1 if ok else 0, "status": "Active"}, "server_info": {}})
            if action == "get_live_streams":
                return self.json(live_streams())
            if action == "get_vod_streams":
                return self.json(vod_streams())
            if action in ("get_simple_data_table", "get_short_epg"):
                if q.get("stream_id") == "601" and ENV("MOCK_NEWS") == "1":
                    return self.json({"epg_listings": news_epg()})
                return self.json({"epg_listings": []})
            return self.json([])
        if p.startswith("/timeshift/"):
            return self.reply(302, headers={"Location": f"http://127.0.0.1:{PORT}/tsplay/vod.m3u8"})
        if p.startswith("/tsplay/"):
            time.sleep(2.5)
            lines = ["#EXTM3U", "#EXT-X-VERSION:3", f"#EXT-X-TARGETDURATION:{SEG_DUR}",
                     "#EXT-X-MEDIA-SEQUENCE:0", "#EXT-X-PLAYLIST-TYPE:VOD"]
            for s in range(NSEG):
                lines += [f"#EXTINF:{SEG_DUR}.000,", f"/seg/vod/{s}.ts"]
            lines.append("#EXT-X-ENDLIST")
            return self.reply(200, ("\n".join(lines) + "\n").encode(), "application/vnd.apple.mpegurl")
        if p.startswith("/live/") and p.endswith(".m3u8"):
            sid = p.rsplit("/", 1)[1].split(".")[0]
            if sid in ENV("MOCK_DENY", "").split(","):
                return self.reply(407)
            if time.time() - T0 < float(ENV("MOCK_BUSY_UNTIL", "0")):
                return self.reply(503, b"Service Unavailable")
            with lock:
                state["tokens"] += 1
                tok = state["tokens"]
            return self.reply(302, headers={"Location": f"http://127.0.0.1:{PORT}/edge/tok{tok}/1"})
        if p.startswith("/edge/"):
            tok = p.split("/")[2]
            with lock:
                edge_hits[tok] = edge_hits.get(tok, 0) + 1
                if edge_hits[tok] == 2 and (MODE == "always" or (MODE == "once" and not state["failed_once"])):
                    dead.add(tok)
                    state["failed_once"] = True
                is_dead = tok in dead
            if is_dead:
                return self.reply(509, b"Bandwidth Limit Exceeded")
            first = max(0, int((time.time() - T0) / SEG_DUR) - 2)
            lines = ["#EXTM3U", "#EXT-X-VERSION:3", f"#EXT-X-TARGETDURATION:{SEG_DUR}",
                     f"#EXT-X-MEDIA-SEQUENCE:{first}"]
            for s in range(first, first + 3):
                lines += [f"#EXTINF:{SEG_DUR}.000,", f"/seg/{tok}/{s}.ts"]
            return self.reply(200, ("\n".join(lines) + "\n").encode(), "application/vnd.apple.mpegurl")
        if p.startswith("/seg/"):
            n = int(p.rsplit("/", 1)[1].split(".")[0])
            with open(os.path.join(SEGDIR, f"seg{n % NSEG}.ts"), "rb") as f:
```

```rust
/// Where the portal credentials come from at startup.
#[derive(Debug, PartialEq, Eq)]
pub enum CredsSource {
    /// Usable credentials: `--xtream` if it has real values, else the ini.
    Configured(XtreamCreds),
    /// Only placeholder values (the zip's run.bat): show the setup prompt.
    Placeholder,
    /// None at all: show the setup prompt.
    Missing,
    /// Unreadable (e.g. a hand-edited ini): show the setup prompt.
    Invalid(String),
}

/// `--xtream` with real values wins, then the ini. Placeholder or unreadable
/// values never stop the app: it shows the setup prompt instead.
pub fn resolve_creds(cli: Option<&str>, ini: Option<&str>) -> CredsSource {
    let mut placeholder = false;
    let mut invalid = None;
    for s in [cli, ini].into_iter().flatten() {
        match parse_xtream_creds(s) {
            Ok(c) if !is_placeholder_creds(&c) => return CredsSource::Configured(c),
            Ok(_) => placeholder = true,
            Err(e) => invalid = invalid.or(Some(e.to_string())),
        }
    }
    match invalid {
        Some(e) => CredsSource::Invalid(e),
        None if placeholder => CredsSource::Placeholder,
        None => CredsSource::Missing,
    }
}
```

```rust
const PATH_KINDS: [&str; 4] = ["/live/", "/movie/", "/series/", "/timeshift/"];

/// `text` with every portal user name and password replaced by `<u>` / `<p>`.
/// Borrows when there is nothing to hide, the common case for log lines.
pub fn redact(text: &str) -> Cow<'_, str> {
    let has_path = PATH_KINDS.iter().any(|k| text.contains(k));
    let has_query = text.contains("username=") || text.contains("password=");
    if !has_path && !has_query {
        return Cow::Borrowed(text);
    }
    let mut out = text.to_string();
    for kind in PATH_KINDS {
        out = redact_path(&out, kind);
    }
    out = redact_query(&out, "username=", "<u>");
    out = redact_query(&out, "password=", "<p>");
    if out == text {
        Cow::Borrowed(text)
    } else {
        Cow::Owned(out)
    }
}

/// `…/live/<user>/<pass>/…` → `…/live/<u>/<p>/…` wherever two path segments,
/// each closed by '/', follow the marker.
fn redact_path(s: &str, kind: &str) -> String {
    let mut out = String::with_capacity(s.len());
    let mut rest = s;
    while let Some(i) = rest.find(kind) {
        let after = i + kind.len();
        out.push_str(&rest[..after]);
        let tail = &rest[after..];
        let end_of_url = tail
            .find(|c: char| c.is_whitespace() || c == '"' || c == '\'')
            .unwrap_or(tail.len());
        let url = &tail[..end_of_url];
        match url.find('/').and_then(|a| url[a + 1..].find('/').map(|b| a + 1 + b)) {
            Some(second_slash) => {
                out.push_str("<u>/<p>");
                rest = &tail[second_slash..];
            }
            None => rest = tail,
        }
    }
    out.push_str(rest);
    out
}

/// `key<value>` → `key<mask>`; the value ends at '&', whitespace, a quote or
/// the end of the text.
fn redact_query(s: &str, key: &str, mask: &str) -> String {
    let mut out = String::with_capacity(s.len());
    let mut rest = s;
    while let Some(i) = rest.find(key) {
        let after = i + key.len();
        out.push_str(&rest[..after]);
        out.push_str(mask);
        let tail = &rest[after..];
        let end = tail
            .find(|c: char| c == '&' || c.is_whitespace() || c == '"' || c == '\'')
            .unwrap_or(tail.len());
        rest = &tail[end..];
    }
    out.push_str(rest);
    out
}
```

```rust
/// Tolerant yes/no flag: `1`, `"1"`, `true` and `"true"` mean yes; anything
/// else, null or a missing field mean no. The portal sends `is_adult` as
/// `"0"`/`"1"`.
fn deser_flag<'de, D>(d: D) -> Result<bool, D::Error>
where
    D: serde::Deserializer<'de>,
{
    use serde::Deserialize as _;
    let v = Option::<serde_json::Value>::deserialize(d).unwrap_or(None);
    Ok(match v {
        Some(serde_json::Value::Bool(b)) => b,
        Some(serde_json::Value::Number(n)) => n.as_i64().unwrap_or(0) != 0,
        Some(serde_json::Value::String(s)) => {
            matches!(s.trim().to_ascii_lowercase().as_str(), "1" | "true")
        }
        _ => false,
    })
}
```

```rust
/// Whether `title` counts as news: it matches at least one plain pattern (or
/// there is none) and no `!`-pattern. Case-insensitive.
pub fn title_matches(patterns: &str, title: &str) -> bool {
    let title = title.to_lowercase();
    let (mut any_plain, mut plain_hit) = (false, false);
    for p in patterns.split(';').map(str::trim).filter(|p| !p.is_empty()) {
        if let Some(excluded) = p.strip_prefix('!') {
            if glob(&excluded.trim().to_lowercase(), &title) {
                return false;
            }
        } else {
            any_plain = true;
            plain_hit |= glob(&p.to_lowercase(), &title);
        }
    }
    !any_plain || plain_hit
}

/// The badge text: the rule's label, else the channel name's first word.
pub fn rule_label(rule: &NewsRule) -> String {
    let label = rule.label.trim();
    if !label.is_empty() {
        return label.to_string();
    }
    rule.channel
        .split_whitespace()
        .next()
        .unwrap_or("")
        .to_uppercase()
}

/// `*`-only wildcard match over the whole text.
fn glob(pattern: &str, text: &str) -> bool {
    let (p, t): (Vec<char>, Vec<char>) = (pattern.chars().collect(), text.chars().collect());
    let (mut pi, mut ti) = (0, 0);
    let (mut star, mut mark) = (None, 0);
    while ti < t.len() {
        if pi < p.len() && p[pi] != '*' && p[pi] == t[ti] {
            pi += 1;
            ti += 1;
        } else if pi < p.len() && p[pi] == '*' {
            star = Some(pi);
            mark = ti;
            pi += 1;
        } else if let Some(s) = star {
            pi = s + 1;
            mark += 1;
            ti = mark;
        } else {
            return false;
        }
    }
    while pi < p.len() && p[pi] == '*' {
        pi += 1;
    }
    pi == p.len()
}
```

```rust
use ring::digest;
use ring::rand::{SecureRandom, SystemRandom};

pub fn valid_pin(pin: &str) -> bool {
    pin.len() == 4 && pin.bytes().all(|b| b.is_ascii_digit())
}

impl PinHash {
    /// A hash of `pin` with a fresh random salt.
    pub fn new(pin: &str) -> Result<Self, PinError> {
        let mut salt = [0u8; 16];
        SystemRandom::new()
            .fill(&mut salt)
            .map_err(|_| PinError::NoRandom)?;
        Self::with_salt(pin, salt)
    }

    pub fn with_salt(pin: &str, salt: [u8; 16]) -> Result<Self, PinError> {
        if !valid_pin(pin) {
            return Err(PinError::NotFourDigits);
        }
        Ok(Self {
            salt: hex(&salt),
            hash: hex(&sha256(&salt, pin)),
        })
    }

    pub fn verify(&self, pin: &str) -> bool {
        let Some(salt) = unhex(&self.salt) else {
            return false;
        };
        valid_pin(pin) && hex(&sha256(&salt, pin)) == self.hash
    }
}

fn sha256(salt: &[u8], pin: &str) -> Vec<u8> {
    let mut ctx = digest::Context::new(&digest::SHA256);
    ctx.update(salt);
    ctx.update(pin.as_bytes());
    ctx.finish().as_ref().to_vec()
}

fn hex(bytes: &[u8]) -> String {
    bytes.iter().map(|b| format!("{b:02x}")).collect()
}

fn unhex(s: &str) -> Option<Vec<u8>> {
    if s.len() % 2 != 0 {
        return None;
    }
    (0..s.len())
        .step_by(2)
        .map(|i| u8::from_str_radix(s.get(i..i + 2)?, 16).ok())
        .collect()
}

impl PinGate {
    /// Time left while PIN input is blocked.
    pub fn wait_left(&self, now: Instant) -> Option<Duration> {
        self.blocked_until
            .and_then(|t| t.checked_duration_since(now))
            .filter(|d| !d.is_zero())
    }

    /// Count an attempt: right resets, the third wrong one in a row blocks.
    pub fn record(&mut self, ok: bool, now: Instant) {
        if ok {
            self.failures = 0;
            self.blocked_until = None;
            return;
        }
        self.failures += 1;
        if self.failures >= Self::MAX_FAILURES {
            self.failures = 0;
            self.blocked_until = Some(now + Self::BLOCK);
        }
    }
}

/// The forgotten-PIN reset: whoever knows the portal password owns the app.
pub fn portal_password_ok(input: &str, actual: &str) -> bool {
    !actual.is_empty() && input == actual
}
```

```rust
//! Every text the user reads, in Dutch, English and German. Channel and
//! programme names come from the portal and are not translated; log lines
//! stay English.

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Lang {
    Nl,
    En,
    De,
}

impl Lang {
    pub const ALL: [Lang; 3] = [Lang::Nl, Lang::En, Lang::De];

    pub fn code(self) -> &'static str {
        match self {
            Lang::Nl => "nl",
            Lang::En => "en",
            Lang::De => "de",
        }
    }

    pub fn from_code(code: &str) -> Option<Lang> {
        match code.trim().to_ascii_lowercase().as_str() {
            "nl" => Some(Lang::Nl),
            "en" => Some(Lang::En),
            "de" => Some(Lang::De),
            _ => None,
        }
    }

    /// The language's own name, for the language choice.
    pub fn native_name(self) -> &'static str {
        match self {
            Lang::Nl => "Nederlands",
            Lang::En => "English",
            Lang::De => "Deutsch",

    }

/// The text for `key` in `lang`.
pub fn t(lang: Lang, key: T) -> &'static str {
    let [nl, en, de] = table(key);
    match lang {
        Lang::Nl => nl,
        Lang::En => en,
        Lang::De => de,
    }
}

/// The text for `key` with `{0}`, `{1}`, … filled from `args`; each language
/// may put them in its own order.
pub fn tr(lang: Lang, key: T, args: &[&str]) -> String {
    let mut s = t(lang, key).to_string();
    for (i, a) in args.iter().enumerate() {
        s = s.replace(&format!("{{{i}}}"), a);
    }
    s
}
```

```rust
//! User preferences in %APPDATA%\BongoPlayer\config\settings.json. Portal
//! credentials stay in BongoPlayer.ini next to the exe (see args.rs).

use crate::i18n::Lang;
use crate::news::{default_rules, NewsRule};
use crate::pin::PinHash;
use serde::{Deserialize, Serialize};
use std::path::Path;

#[derive(Debug, Clone, Default, PartialEq, Serialize, Deserialize)]
pub struct Settings {
    /// "nl" / "en" / "de"; absent until the first-start language choice.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub language: Option<String>,
    #[serde(default)]
    pub swap_zap_keys: bool,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub pin: Option<PinHash>,
    /// Absent = the default rules; an empty list is the user's own choice.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub news_rules: Option<Vec<NewsRule>>,
}

impl Settings {
    /// The saved preferences. A missing file gives the defaults; a broken one
    /// too, with a warning; one bad value costs only that value.
    pub fn load(path: &Path) -> Self {
        let Ok(text) = std::fs::read_to_string(path) else {
            return Self::default();
        };
        // Notepad's "UTF-8 with BOM" puts U+FEFF first; JSON does not allow it.
        let text = text.strip_prefix('\u{feff}').unwrap_or(&text);
        match serde_json::from_str::<serde_json::Value>(text) {
            Ok(v) => Self::from_value(&v),
            Err(e) => {
                tracing::warn!(
                    "settings: {} is not valid JSON ({}) - using defaults",
                    path.display(),
                    e
                );
                Self::default()
            }
        }
    }

    fn from_value(v: &serde_json::Value) -> Self {
        Self {
            language: v
                .get("language")
                .and_then(|x| x.as_str())
                .filter(|code| Lang::from_code(code).is_some())
                .map(str::to_string),
            swap_zap_keys: v
                .get("swap_zap_keys")
                .and_then(|x| x.as_bool())
                .unwrap_or(false),
            pin: v
                .get("pin")
                .and_then(|x| serde_json::from_value(x.clone()).ok()),
            news_rules: v
                .get("news_rules")
                .and_then(|x| serde_json::from_value(x.clone()).ok()),
        }
    }

    /// Write atomically: a temp file next to it, then a rename.
    pub fn save(&self, path: &Path) -> std::io::Result<()> {
        if let Some(dir) = path.parent() {
            std::fs::create_dir_all(dir)?;
        }
        let text = serde_json::to_string_pretty(self).map_err(std::io::Error::other)?;
        let tmp = path.with_extension("json.tmp");
        std::fs::write(&tmp, text)?;
        std::fs::rename(&tmp, path)
    }

    pub fn lang(&self) -> Option<Lang> {
        self.language.as_deref().and_then(Lang::from_code)
    }

    pub fn news_rules_or_default(&self) -> Vec<NewsRule> {
        self.news_rules.clone().unwrap_or_else(default_rules)
    }
}
```

```rust
fn language_pane(
    ui: &mut egui::Ui,
    view: &SettingsView,
    focus_first: bool,
    actions: &mut Vec<SettingsAction>,
) {
    for (i, l) in Lang::ALL.iter().enumerate() {
        let r = ui.radio(view.lang == *l, l.native_name());
        if focus_first && i == 0 {
            r.request_focus();
        }
        if r.clicked() && view.lang != *l {
            actions.push(SettingsAction::SetLanguage(*l));
        }
    }

    ui: &mut egui::Ui,
    view: &SettingsView,
    focus_first: bool,

            *selected = Lang::ALL[pos.saturating_sub(1)];
        }
        if i.consume_key(Modifiers::NONE, Key::Enter) {
            picked = Some(*selected);
        }
    });
    egui::CentralPanel::default()
        .frame(egui::Frame::none().fill(Color32::from_rgb(14, 14, 18)))

            ui.vertical_centered(|ui| {
                ui.add_space(ui.available_height() * 0.25);

                        .size(28.0)
                        .color(Color32::WHITE),
```

```rust
/// Outcome of trying portal credentials (settings screen, setup prompt).
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum ConnCheck {
    Ok { channels: usize },
    BadLogin,
    Unreachable,
    Invalid,
}

impl XtreamPortal {
    /// Log in with these credentials and count the live channels, within 10 s.
    pub async fn check(&self) -> ConnCheck {
        tokio::time::timeout(std::time::Duration::from_secs(10), self.check_inner())
            .await
            .unwrap_or(ConnCheck::Unreachable)
    }

    async fn check_inner(&self) -> ConnCheck {
        let login = match self.client.get(self.api_url(&[])).send().await {
            Ok(r) => r,
            Err(_) => return ConnCheck::Unreachable,
        };
        if matches!(login.status().as_u16(), 401 | 403) {
            return ConnCheck::BadLogin;
        }
        let Ok(v) = login.json::<serde_json::Value>().await else {
            return ConnCheck::Invalid;
        };
        let Some(auth) = v.get("user_info").and_then(|u| u.get("auth")) else {
            return ConnCheck::Invalid;
        };
        if !(auth.as_i64() == Some(1) || auth.as_str() == Some("1")) {
            return ConnCheck::BadLogin;
        }
        match self
            .client
            .get(self.api_url(&[("action", "get_live_streams")]))
            .send()
            .await
        {
            Ok(r) => match r.json::<Vec<serde_json::Value>>().await {
                Ok(list) => ConnCheck::Ok { channels: list.len() },
                Err(_) => ConnCheck::Invalid,
            },
            Err(_) => ConnCheck::Unreachable,
        }
    }
}
```

```rust
/// The channel a rule points at: its catch-up twin when there is one (EPG
/// and replays live there), else the live channel. Exact normalized name
/// first, then a name that contains it ("CNN" finds "CNN International").
pub fn resolve_channel(
    live: &[crate::portal::LiveChannel],
    rule: &NewsRule,
) -> Option<(i64, bool, String)> {
    use crate::catalog::normalize_channel_name;
    let key = normalize_channel_name(&rule.channel);
    if key.is_empty() {
        return None;
    }
    let pick = |archive: bool| {
        let kind = |c: &&crate::portal::LiveChannel| (c.tv_archive == 1) == archive;
        live.iter()
            .filter(kind)
            .find(|c| normalize_channel_name(&c.name) == key)
            .or_else(|| {
                live.iter()
                    .filter(kind)
                    .find(|c| normalize_channel_name(&c.name).contains(&key))
            })
            .map(|c| (c.stream_id, archive, c.name.clone()))
    };
    pick(true).or_else(|| pick(false))
}
```

```rust
            });
        if let Some(i) = remove {
            rules.remove(i);
            changed = true;
        }
        ui.horizontal(|ui| {
            let add = ui.button(t(lang, T::NewsAddRule));
            // Without rules there is no first field: start on this button.
            if focus_first && rules.is_empty() {
                add.request_focus();
            }
            if add.clicked() {
                rules.push(NewsRule {
                    channel: String::new(),
                    patterns: "*".into(),
                    label: String::new(),
                    skip_secs: 0,
                });
                changed = true;
            }
            if ui.button(t(lang, T::NewsRestoreDefaults)).clicked() {
                *rules = default_rules();
                changed = true;
            }
        });
        ui.label(
            egui::RichText::new(t(lang, T::NewsPatternsHelp))
                .small()
                .color(Color32::from_white_alpha(120)),
        );
        if changed {
            actions.push(SettingsAction::SetNewsRules(rules.clone()));
        }
    }
}
```
