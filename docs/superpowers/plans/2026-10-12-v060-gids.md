# Bongo Player 0.6.0 part 2: the guide — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the guide (`g`) with an NLZIET-style guide for the ~200 channels that have EPG: live and catch-up in one list, per-column scrolling, a date list, a filter box, logos, EPG fetched gently and kept in a cache file, and a wait screen while catch-up loads.

**Architecture:** A new `guide/` module holds the guide's data and draws nothing: time arithmetic (`time.rs`), the EPG store, fetch order and filter (`store.rs`), the background fetcher (`fetch.rs`), the cache file (`cache.rs`) and the channel logos (`logos.rs`, which hands egui textures over but draws nothing). A new `guide_ui.rs` draws the guide and returns a `GuideAction`, as `settings_ui.rs` does; `app.rs` plays what was picked (relay, catch-up, wait screen) and loses the old guide. The catalog builds the guide's channel list once per catalog and stays the only adult filter.

**Tech Stack:** Rust 2021, egui/eframe 0.27.2, tokio, reqwest 0.12, chrono 0.4.44, serde/serde_json, ring (SHA-256), image 0.24 (PNG only, already pulled in by eframe), wiremock (tests).

**Spec:** `docs/superpowers/specs/2026-10-12-v060-gids-design.md`

## Global Constraints

- **Performance is binding.** Startup is not slower than 0.5.2: the A/B script against the 0.5.2 release exe, at least 10 runs each, median and minimum within ±10 %. Per frame, no work or allocation that grows with the catalog (~13k channels) or with the size of the EPG; only work proportional to the visible rows of the visible columns (a binary search per visible column is fine). With a loaded cache the columns show within one frame after `g`. Zapping is not slower: EPG fetching pauses while a stream starts (from the load until `PlaybackStarted`, 10 s at most) and runs at most 1 request at a time while the guide is closed. The EPG store stays under 15 MB for ~200 channels.

## Review Focus

Five inputs the spec implies but no test of the plain feature exercises, most likely to bite first. Each has its test in the owning task.

1. **EPG that lands after the guide lined up** (a slow channel): that column lines up on its target when its data arrives; it does not stay at the top. → Task 9, `a_column_whose_epg_lands_late_lines_up_when_it_lands`.
2. **The portal answers the day table with a non-2xx status** (503/509 busy, an HTML error page): the fetcher backs off 5 → 10 → 30 s instead of storing an empty guide and asking again at once. → Task 2, `a_busy_day_table_is_an_error_not_an_empty_guide`; Task 6, `a_failed_fetch_backs_off_and_nothing_is_stored`.
3. **The clock passes midnight while the guide is open in Nu & straks:** the day follows today, so the live programme stays on the now-line. → Task 9, `now_and_next_follows_the_day_past_midnight`.
4. **A filter that matches nothing:** the guide says so instead of showing an empty screen. → Task 10, `a_filter_that_matches_nothing_says_so`.
5. **Lock or unlock while the guide is open:** the column list shrinks or grows under the page and the cursor; both stay valid, nothing panics, no adult column stays. → Task 11, `locking_with_the_guide_open_drops_the_adult_column_and_keeps_the_page_valid`.

## Refinements of the spec made by this plan

The spec is the authority; these points refine it where it is silent or where a literal reading would hurt. Task 15 writes them into the spec.

- **`guide.rs` is a folder `guide/`** of five focused files (`time`, `store`, `fetch`, `cache`, `logos`); `logos.rs` hands egui textures over but draws nothing.
- **Writing the cache file:** once what came in is complete (nothing in flight, no guide channel left to fetch), or after a minute of fetching; not at a pause of the fetching (a stream that starts), which would write a file with a few channels.

- **Nested programmes** (`clean_entries`): an entry with another title that lies wholly inside the one before it is dropped; the enclosing programme stays. Clipping the enclosing one there would leave a gap after the short one.
- **Day slices** are two binary searches per visible column per frame (`time::day_slice`), not a cache. O(log n) per column fits the performance rule, and nothing has to be invalidated.
- **A failed day table** is not followed by the short EPG at once: an error backs off (the portal is busy); only an empty day table falls back to the short EPG.
- **Wait screen:** an `EndOfFile` with reason `eof` before the first frame counts as a failure too (nothing played); the wait screen takes only Esc and `g`.

```rust
/// "HH:MM" of `t` in time zone `tz`.
pub fn hhmm_in<Tz: chrono::TimeZone>(t: DateTime<Utc>, tz: &Tz) -> String
where
    Tz::Offset: std::fmt::Display,
{
    t.with_timezone(tz).format("%H:%M").to_string()
}

/// "HH:MM" of `t` in the computer's local time: how programme times show.
pub fn hhmm(t: DateTime<Utc>) -> String {
    hhmm_in(t, &chrono::Local)
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct EpgEntry {
    pub title: String,
    pub start: DateTime<Utc>,
    pub end: DateTime<Utc>,

        &self.entries
    }

    pub fn current_at(&self, t: DateTime<Utc>) -> Option<&EpgEntry> {
        self.entries.iter().find(|e| e.start <= t && t < e.end)
    }

    pub fn next_at(&self, t: DateTime<Utc>) -> Option<&EpgEntry> {
        self.entries.iter().find(|e| e.start > t)

}

/// Whether two titles name the same programme: trimmed, in any case.
fn same_title(a: &str, b: &str) -> bool {

    a.eq_ignore_ascii_case(b) || a.to_lowercase() == b.to_lowercase()
}

/// `has_archive` of two entries of one programme, merged: watchable when either
/// says so, unknown when neither says anything.
fn merge_archive(a: Option<bool>, b: Option<bool>) -> Option<bool> {
    match (a, b) {
        (Some(true), _) | (_, Some(true)) => Some(true),
        (None, None) => None,
        _ => Some(false),
    }
}

/// A portal listing made fit for a guide in which one programme runs at a time.
/// This portal's EPG holds the same programme twice a few minutes apart, and
/// programmes that overlap the next one; the 0.5 guide showed both as LIVE.
///
/// - Entries that do not end after they start go.
/// - The rest is sorted by start; entries that start together keep the
///   portal's order.
/// - An entry that overlaps the one kept before it:
///   - with the same title (trimmed, any case) is merged into it, which then
///     ends at the later of the two ends;
///   - that starts together with it, or lies wholly inside it, is dropped;
///   - otherwise ends that one: it ends where this one starts.
///
/// The result is sorted, no two entries overlap, and each ends after it starts.
pub fn clean_entries(mut entries: Vec<EpgEntry>) -> Vec<EpgEntry> {
    entries.retain(|e| e.end > e.start);
    entries.sort_by_key(|e| e.start);
    let mut out: Vec<EpgEntry> = Vec::with_capacity(entries.len());
    for e in entries {
        let Some(prev) = out.last_mut() else {
            out.push(e);
            continue;
        };
        if e.start >= prev.end {
            out.push(e);
        } else if same_title(&prev.title, &e.title) {
            prev.end = prev.end.max(e.end);
            prev.has_archive = merge_archive(prev.has_archive, e.has_archive);
        } else if e.start == prev.start || e.end <= prev.end {
            // The one already kept stays.
        } else {
            prev.end = e.start;
            out.push(e);
        }
    }
    out
}
```

```rust
/// One column of the guide: a channel that has a catch-up (archive) variant,
/// all its variants merged. On this portal only the catch-up variants carry
/// EPG, so these are the channels the guide can fill.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct GuideChannel {
    /// The name the column shows: the live variant's, else the catch-up one's.
    pub name: String,
    /// What plays live: the live variant zapping would pick, else `archive_id`.
    pub live_id: i64,
    /// Where the EPG and catch-up come from.
    pub archive_id: i64,
    /// How many days back catch-up reaches; 0 when the portal does not say.
    pub archive_days: u32,
    /// The logo URL, if the portal has one.
    pub logo: Option<String>,
    /// A variant of the channel carries the portal's adult flag.
    pub adult: bool,
}

/// The guide's channels in `live`: one per channel ([`normalize_channel_name`])
/// that has a catch-up variant (`tv_archive == 1`), in the order the channels
/// first appear. Of several live or catch-up variants the one zapping would
/// pick wins ([`zap_preference`]); on a tie, the first.
pub fn guide_channels_of(live: &[LiveChannel]) -> Vec<GuideChannel> {
    let mut order: Vec<String> = Vec::new();
    let mut groups: HashMap<String, Vec<&LiveChannel>> = HashMap::new();
    for ch in live {
        let key = normalize_channel_name(&ch.name);
        if key.is_empty() {
            continue;
        }
        groups
            .entry(key)
            .or_insert_with_key(|k| {
                order.push(k.clone());
                Vec::new()
            })
            .push(ch);
    }
    order
        .iter()
        .filter_map(|key| {
            let group = groups.get(key)?;
            let best = |archive: bool| {
                group
                    .iter()
                    .copied()
                    .filter(|c| (c.tv_archive == 1) == archive)
                    .fold(None::<&LiveChannel>, |best, c| match best {
                        Some(b)
                            if zap_preference(quality_rank(&b.name))
                                >= zap_preference(quality_rank(&c.name)) =>
                        {
                            Some(b)
                        }
                        _ => Some(c),
                    })
            };
            let archive = best(true)?;
            let live_variant = best(false);
            let shown = live_variant.unwrap_or(archive);
            let logo = live_variant
                .into_iter()
                .chain(Some(archive))
                .filter_map(|c| c.stream_icon.as_deref())
                .map(str::trim)
                .find(|s| !s.is_empty())
                .map(str::to_owned);
            Some(GuideChannel {
                name: shown.name.clone(),
                live_id: shown.stream_id,
                archive_id: archive.stream_id,
                archive_days: u32::try_from(archive.tv_archive_duration).unwrap_or(0),
                logo,
                adult: group.iter().any(|c| adult_live(c)),
            })
        })
        .collect()
}
```

```rust
        date(2026, 10, 25).and_hms_opt(1, 0, 0).unwrap()

    impl TimeZone for SwitchZone {
        type Offset = FixedOffset;

        fn from_offset(_: &FixedOffset) -> Self {
            SwitchZone

        fn offset_from_local_date(&self, local: &NaiveDate) -> MappedLocalTime<FixedOffset> {
            self.offset_from_local_datetime(&local.and_hms_opt(0, 0, 0).unwrap())

        fn offset_from_local_datetime(
            &self,
            local: &NaiveDateTime,
        ) -> MappedLocalTime<FixedOffset> {
            // 02:00-03:00 local happens twice: in summer time, then in winter time.
            if *local < switch_utc() + Duration::hours(1) {
                MappedLocalTime::Single(east(2))
            } else if *local >= switch_utc() + Duration::hours(2) {
                MappedLocalTime::Single(east(1))
            } else {
                MappedLocalTime::Ambiguous(east(2), east(1))
            }
        }

        fn offset_from_utc_date(&self, utc: &NaiveDate) -> FixedOffset {
            self.offset_from_utc_datetime(&utc.and_hms_opt(0, 0, 0).unwrap())
        }

        fn offset_from_utc_datetime(&self, utc: &NaiveDateTime) -> FixedOffset {
            if *utc < switch_utc() {
                east(2)
            } else {
                east(1)
            }
        }
```

```rust
//! Days, targets and what a programme is for the viewer. Every function that
//! depends on the time zone takes it as a parameter (`_in`), with a wrapper in
//! the computer's local time, so the tests can use fixed zones and a zone with
//! a daylight-saving switch.

use crate::epg::EpgEntry;
use chrono::{DateTime, Duration, Local, NaiveDate, TimeZone, Utc};
use std::ops::Range;

/// Primetime starts at 19:00 (the docx: "focus on prime time (19:00)").
pub const PRIMETIME_HOUR: u32 = 19;

/// What a programme in the guide is for the viewer.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Playable {
    /// On now: plays live.
    Live,
    /// Over and kept by the portal: plays from its start through catch-up.
    Replay,
    /// Over and not (or no longer) kept.
    Unavailable,
    /// Not on yet.
    Future,
}

/// What `entry` is at `now` on a channel whose catch-up reaches `archive_days`
/// back (0: the portal did not say, so every past programme counts). The
/// programme's own `has_archive` counts only when `trust_flag` is set, that is
/// when the portal sends `has_archive = 1` for some programme of this channel:
/// a portal that sends 0 (or nothing) for everything would otherwise make
/// nothing watchable.
pub fn playable(
    entry: &EpgEntry,
    archive_days: u32,
    trust_flag: bool,
    now: DateTime<Utc>,
) -> Playable {
    if entry.start > now {
        return Playable::Future;
    }
    if now < entry.end {
        return Playable::Live;
    }
    let in_window =
        archive_days == 0 || entry.start >= now - Duration::days(i64::from(archive_days));
    let flag_allows = !trust_flag || entry.has_archive != Some(false);
    if in_window && flag_allows {
        Playable::Replay
    } else {
        Playable::Unavailable
    }
}

/// The moment `hour`:00 on `day` in `tz`, as UTC: the first of the two when
/// the clock goes back over it, the next whole hour that exists when the clock
/// skips it.
pub fn at_hour_in<Tz: TimeZone>(day: NaiveDate, hour: u32, tz: &Tz) -> DateTime<Utc> {
    (hour..24)
        .find_map(|h| tz.from_local_datetime(&day.and_hms_opt(h, 0, 0)?).earliest())
        .map(|t| t.with_timezone(&Utc))
        // No zone skips the rest of a day: read the date as UTC then.
        .unwrap_or_else(|| {
            Utc.from_utc_datetime(&day.and_hms_opt(hour.min(23), 0, 0).expect("a whole hour"))
        })
}

/// The moment the day `day` starts in `tz` (local midnight), as UTC.
pub fn day_start_in<Tz: TimeZone>(day: NaiveDate, tz: &Tz) -> DateTime<Utc> {
    at_hour_in(day, 0, tz)
}

/// The day `t` falls on in `tz`.
pub fn day_of_in<Tz: TimeZone>(t: DateTime<Utc>, tz: &Tz) -> NaiveDate {
    t.with_timezone(tz).date_naive()
}

/// The programmes of `day` in a cleaned listing (sorted, no overlaps; see
/// [`crate::epg::clean_entries`]): those that start on that day, plus the one
/// that runs at its midnight. Two binary searches: cheap enough per frame.
pub fn day_slice_in<Tz: TimeZone>(entries: &[EpgEntry], day: NaiveDate, tz: &Tz) -> Range<usize> {
    let from = day_start_in(day, tz);
    let to = day_start_in(day.succ_opt().unwrap_or(day), tz);
    let first = entries.partition_point(|e| e.end <= from);
    let end = entries.partition_point(|e| e.start < to);
    first..end.max(first)
}

/// [`at_hour_in`] in the computer's local time.
pub fn at_hour(day: NaiveDate, hour: u32) -> DateTime<Utc> {
    at_hour_in(day, hour, &Local)
}

/// [`day_start_in`] in the computer's local time.
pub fn day_start(day: NaiveDate) -> DateTime<Utc> {
    day_start_in(day, &Local)
}

/// [`day_of_in`] in the computer's local time.
pub fn day_of(t: DateTime<Utc>) -> NaiveDate {
    day_of_in(t, &Local)
}

/// [`day_slice_in`] in the computer's local time.
pub fn day_slice(entries: &[EpgEntry], day: NaiveDate) -> Range<usize> {
    day_slice_in(entries, day, &Local)
}

/// The row a column lines up on: within `range`, the programme running at `t`;
/// in a gap the first one after it; after the last one, the last. `None` when
/// the range is empty.
pub fn target_index(entries: &[EpgEntry], range: Range<usize>, t: DateTime<Utc>) -> Option<usize> {
    let day = entries.get(range.clone())?;
    if day.is_empty() {
        return None;
    }
    let i = day.partition_point(|e| e.end <= t);
    Some(range.start + i.min(day.len() - 1))
}

/// With a filter: the first match (entry indices, ascending) that runs at or
/// after `t`, else the last match.
pub fn match_target(entries: &[EpgEntry], matches: &[usize], t: DateTime<Utc>) -> Option<usize> {
    matches
        .iter()
        .copied()
        .find(|&i| entries.get(i).is_some_and(|e| e.end > t))
        .or_else(|| matches.last().copied())
}

/// The days the date list offers: from `today` minus the longest catch-up of
/// the guide's channels (7 days when no channel says; never over 31) to the
/// last day with programmes, at least today and at most a week ahead.
pub fn date_range(
    today: NaiveDate,
    max_archive_days: u32,
    last_day: Option<NaiveDate>,
) -> Vec<NaiveDate> {
    let back = if max_archive_days == 0 {
        7
    } else {
        max_archive_days.min(31)
    };
    let first = today - Duration::days(i64::from(back));
    let last = last_day
        .unwrap_or(today)
        .clamp(today, today + Duration::days(7));
    first.iter_days().take_while(|d| *d <= last).collect()
}
```

```rust
const WEEKDAYS: [[&str; 7]; 3] = [
    ["ma", "di", "wo", "do", "vr", "za", "zo"],
    ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"],
    ["Mo", "Di", "Mi", "Do", "Fr", "Sa", "So"],
];
const MONTHS: [[&str; 12]; 3] = [
    ["jan", "feb", "mrt", "apr", "mei", "jun", "jul", "aug", "sep", "okt", "nov", "dec"],
    ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"],
    ["Jan", "Feb", "Mär", "Apr", "Mai", "Jun", "Jul", "Aug", "Sep", "Okt", "Nov", "Dez"],
];

/// How the guide names `day`: "Gisteren", "Vandaag", "Morgen", else weekday,
/// day and month ("do 8 okt", "Thu 8 Oct", "Do. 8. Okt.").
pub fn day_label(lang: Lang, day: chrono::NaiveDate, today: chrono::NaiveDate) -> String {
    use chrono::Datelike;
    match (day - today).num_days() {
        -1 => t(lang, T::DayYesterday).to_string(),
        0 => t(lang, T::DayToday).to_string(),
        1 => t(lang, T::DayTomorrow).to_string(),
        _ => {
            let row = match lang {
                Lang::Nl => 0,
                Lang::En => 1,
                Lang::De => 2,
            };
            let weekday = WEEKDAYS[row][day.weekday().num_days_from_monday() as usize];
            let month = MONTHS[row][day.month0() as usize];
            match lang {
                Lang::De => format!("{weekday}. {}. {month}.", day.day()),
                _ => format!("{weekday} {} {month}", day.day()),
            }
        }
    }
}
```

```rust
//! The guide's EPG in memory, which channels need fetching and in what order,
//! and the filter.

use crate::catalog::GuideChannel;
use crate::epg::{Epg, EpgEntry};
use chrono::{DateTime, Duration, NaiveDate, Utc};
use std::collections::HashMap;
use std::ops::Range;
use std::sync::Arc;

/// A channel's EPG as fetched, or as read from the cache file.
#[derive(Debug, Clone)]
pub struct ChannelEpg {
    /// Shared: the cache file is written from copies of these handles, on
    /// another thread.
    pub epg: Arc<Epg>,
    pub fetched_at: DateTime<Utc>,
    /// The portal sends `has_archive = 1` for some programme of this channel,
    /// so its 0 means "not kept" (see `time::playable`).
    pub trusts_archive_flag: bool,
}

impl ChannelEpg {
    pub fn new(epg: Epg, fetched_at: DateTime<Utc>) -> Self {
        let trusts_archive_flag = epg.entries().iter().any(|e| e.has_archive == Some(true));
        Self {
            epg: Arc::new(epg),
            fetched_at,
            trusts_archive_flag,
        }
    }

    pub fn entries(&self) -> &[EpgEntry] {
        self.epg.entries()
    }
}

/// The EPG of the guide's channels, by catch-up (archive) stream id.
#[derive(Debug, Default)]
pub struct EpgStore {
    channels: HashMap<i64, ChannelEpg>,
    /// Counts every change: what the screen works out from the store (the
    /// filter, the date list) is worked out again when it moves.
    revision: u64,
}

impl EpgStore {
    pub fn get(&self, archive_id: i64) -> Option<&ChannelEpg> {
        self.channels.get(&archive_id)
    }

    /// Keeps `epg` for the channel. A copy fetched earlier than the one kept
    /// (the cache file, read after a fetch already landed) changes nothing.
    pub fn insert(&mut self, archive_id: i64, epg: ChannelEpg) {
        if self
            .channels
            .get(&archive_id)
            .is_some_and(|kept| kept.fetched_at > epg.fetched_at)
        {
            return;
        }
        self.channels.insert(archive_id, epg);
        self.revision += 1;
    }

    pub fn revision(&self) -> u64 {
        self.revision
    }

    /// How many channels have EPG.
    pub fn len(&self) -> usize {
        self.channels.len()
    }

    pub fn is_empty(&self) -> bool {
        self.channels.is_empty()
    }

    /// How many programmes the store holds, for the log.
    pub fn programmes(&self) -> usize {
        self.channels.values().map(|c| c.entries().len()).sum()
    }

    /// Whether the channel must be fetched (again): never fetched; fetched 6
    /// hours ago or longer; or with less than 24 hours of programmes ahead and
    /// fetched an hour ago or longer.
    pub fn needs_fetch(&self, archive_id: i64, now: DateTime<Utc>) -> bool {
        let Some(c) = self.channels.get(&archive_id) else {
            return true;
        };
        let age = now - c.fetched_at;
        if age >= Duration::hours(6) {
            return true;
        }
        let ahead = c
            .entries()
            .last()
            .is_some_and(|e| e.end > now + Duration::hours(24));
        !ahead && age >= Duration::hours(1)
    }

    /// The last day on which any channel has a programme (`day_of` names the
    /// day of a moment).
    pub fn last_day(&self, day_of: impl Fn(DateTime<Utc>) -> NaiveDate) -> Option<NaiveDate> {
        self.channels
            .values()
            .filter_map(|c| c.entries().last())
            .map(|e| day_of(e.start))
            .max()
    }

    /// Forgets everything: another portal's catalog took over.
    pub fn clear(&mut self) {
        self.channels.clear();
        self.revision += 1;
    }

    /// Handles to every channel's EPG, for the cache file.
    pub fn snapshot(&self) -> Vec<(i64, ChannelEpg)> {
        self.channels
            .iter()
            .map(|(id, c)| (*id, c.clone()))
            .collect()
    }
}

/// The order in which the guide's channels are fetched: the columns on screen
/// (`shown`, a range of indices into the guide's list), then the ones after
/// them, then the ones before them, nearest first. Allocates nothing.
pub fn fetch_order(shown: Range<usize>, total: usize) -> impl Iterator<Item = usize> {
    let start = shown.start.min(total);
    let end = shown.end.min(total).max(start);
    (start..end).chain(end..total).chain((0..start).rev())
}

/// What a filter leaves of the guide on one day.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct FilterResult {
    /// Indices into the guide's channel list, in its order.
    pub channels: Vec<usize>,
    /// Per catch-up id: the indices of the programmes whose title holds the
    /// text, ascending.
    pub matches: HashMap<i64, Vec<usize>>,
}

/// The channels whose name holds `text` (trimmed, any case), or that have a
/// programme within `range_of(entries)` (the chosen day) whose title holds it.
/// Run when the text, the day or the store changes, never per frame.
pub fn filter_channels(
    channels: &[GuideChannel],
    store: &EpgStore,
    text: &str,
    range_of: impl Fn(&[EpgEntry]) -> Range<usize>,
) -> FilterResult {
    let needle = text.trim().to_lowercase();
    let mut result = FilterResult::default();
    if needle.is_empty() {
        result.channels = (0..channels.len()).collect();
        return result;
    }
    for (i, ch) in channels.iter().enumerate() {
        let by_name = ch.name.to_lowercase().contains(&needle);
        let hits: Vec<usize> = store
            .get(ch.archive_id)
            .map(|c| {
                let entries = c.entries();
                range_of(entries)
                    .filter(|&j| entries[j].title.to_lowercase().contains(&needle))
                    .collect()
            })
            .unwrap_or_default();
        if by_name || !hits.is_empty() {
            result.channels.push(i);
            if !hits.is_empty() {
                result.matches.insert(ch.archive_id, hits);
            }
        }
    }
    result
}
```

```rust
//! Fetching the guide's EPG in the background, gently: the portal throttles
//! bursts, so the guide asks for a channel or two at a time and rests after a
//! failure.

use super::store::EpgStore;
use crate::epg::Epg;
use crate::portal::Portal;
use chrono::{DateTime, Utc};
use parking_lot::Mutex;
use std::collections::{HashMap, HashSet};
use std::sync::Arc;
use std::time::{Duration, Instant};

/// A fetch that finished, on its way to the UI thread.
#[derive(Debug)]
pub struct Fetched {
    pub archive_id: i64,
    /// The error's text on failure (credentials masked, see `PortalError`).
    pub result: Result<Epg, String>,
}

/// After this many failures of one channel it is left alone for the rest of
/// the session (or until another portal).
const MAX_FAILURES: u8 = 3;

/// How long to rest after this many failures in a row: 5 s, 10 s, then 30 s.
fn rest_after(failures_in_a_row: u32) -> Duration {
    match failures_in_a_row {
        0 => Duration::ZERO,
        1 => Duration::from_secs(5),
        2 => Duration::from_secs(10),
        _ => Duration::from_secs(30),
    }
}

/// Starts the guide's EPG fetches, a few at a time, and takes their results in.
pub struct EpgFetcher {
    portal: Arc<dyn Portal>,
    /// Where finished fetches land. A new one after `reset`: the old portal's
    /// fetches finish into a slot nobody reads any more.
    done: Arc<Mutex<Vec<Fetched>>>,
    in_flight: HashSet<i64>,
    failures: HashMap<i64, u8>,
    failures_in_a_row: u32,
    /// No new fetch before this moment (resting after a failure).
    not_before: Option<Instant>,
}

impl EpgFetcher {
    pub fn new(portal: Arc<dyn Portal>) -> Self {
        Self {
            portal,
            done: Arc::new(Mutex::new(Vec::new())),
            in_flight: HashSet::new(),
            failures: HashMap::new(),
            failures_in_a_row: 0,
            not_before: None,
        }
    }

    /// Another portal took over: start afresh.
    pub fn reset(&mut self, portal: Arc<dyn Portal>) {
        *self = Self::new(portal);
    }

    /// Catch-up ids being fetched now.
    pub fn in_flight(&self) -> &HashSet<i64> {
        &self.in_flight
    }

    /// Starts fetches while fewer than `limit` run, taking channels (catch-up
    /// ids) in `order` and skipping the ones in flight, the ones the store has
    /// fresh and the ones that failed too often. Nothing while resting after a
    /// failure. Called every frame: returns at once when nothing can start.
    pub fn tick(
        &mut self,
        store: &EpgStore,
        order: impl Iterator<Item = i64>,
        limit: usize,
        now: Instant,
        utc_now: DateTime<Utc>,
    ) {
        if self.in_flight.len() >= limit || self.not_before.is_some_and(|t| now < t) {
            return;
        }
        let mut free = limit - self.in_flight.len();
        for id in order {
            if free == 0 {
                break;
            }
            if self.in_flight.contains(&id)
                || self.failures.get(&id).is_some_and(|&n| n >= MAX_FAILURES)
                || !store.needs_fetch(id, utc_now)
            {
                continue;
            }
            self.start(id);
            free -= 1;
        }
    }

    fn start(&mut self, archive_id: i64) {
        self.in_flight.insert(archive_id);
        let (portal, done) = (self.portal.clone(), self.done.clone());
        tokio::spawn(async move {
            let result = fetch_one(portal.as_ref(), archive_id).await;
            done.lock().push(Fetched { archive_id, result });
        });
    }

    /// The fetches that finished since the last call. A failure counts for its
    /// channel and makes the fetcher rest from `now` (5, 10, then 30 s).
    pub fn drain(&mut self, now: Instant) -> Vec<Fetched> {
        let finished = std::mem::take(&mut *self.done.lock());
        for f in &finished {
            self.in_flight.remove(&f.archive_id);
            match &f.result {
                Ok(_) => self.failures_in_a_row = 0,
                Err(e) => {
                    *self.failures.entry(f.archive_id).or_insert(0) += 1;
                    self.failures_in_a_row += 1;
                    let rest = rest_after(self.failures_in_a_row);
                    self.not_before = Some(now + rest);
                    tracing::warn!(
                        "guide: epg fetch failed for sid={} ({}) - resting {} s",
                        f.archive_id,
                        e,
                        rest.as_secs()
                    );
                }
            }
        }
        finished
    }
}

/// One channel's day table. An empty one falls back to the short EPG (some
/// portals fill only that); a failed one is a failure: the portal is busy or
/// broken, and asking it again at once would only add to that.
async fn fetch_one(portal: &dyn Portal, archive_id: i64) -> Result<Epg, String> {
    let day = portal
        .fetch_day_epg(archive_id)
        .await
        .map_err(|e| e.to_string())?;
    if !day.entries().is_empty() {
        return Ok(day);
    }
    Ok(portal.fetch_epg(archive_id).await.unwrap_or_default())
```

```rust
//! The guide's EPG in a file, so a restart has the whole guide at once: "het
//! kan zijn dat je net de app hebt afgesloten met de hele gids er al in".

use super::store::ChannelEpg;
use crate::epg::{Epg, EpgEntry};
use chrono::{DateTime, Duration, TimeZone, Utc};
use serde::{Deserialize, Serialize};
use std::path::Path;

const VERSION: u32 = 1;

#[derive(Serialize, Deserialize)]
struct CacheFile {
    version: u32,
    channels: Vec<CachedChannel>,
}

#[derive(Serialize, Deserialize)]
struct CachedChannel {
    id: i64,
    fetched_at: i64,
    /// `[start, end, title, has_archive]`: epoch seconds, and 1, 0 or null.
    entries: Vec<(i64, i64, String, Option<u8>)>,
}

/// The cache file of the portal at `host`:`port`: `epg-<host>_<port>.json`,
/// every character but letters, digits, '.' and '-' turned into '_'. The user
/// name and password never go into it.
pub fn file_name(host: &str, port: u16) -> String {
    let host: String = host
        .chars()
        .map(|c| {
            if c.is_ascii_alphanumeric() || c == '.' || c == '-' {
                c
            } else {
                '_'
            }
        })
        .collect();
    format!("epg-{host}_{port}.json")
}

/// A channel to write: its catch-up id, its EPG, and how far back its
/// catch-up reaches (0: the portal does not say).
pub struct ToSave {
    pub id: i64,
    pub epg: ChannelEpg,
    pub archive_days: u32,
}

/// Writes the file at `path`: a temporary file next to it, renamed over it, so
/// a crash halfway leaves the old one. Programmes that ended before catch-up
/// reaches (plus a day; 14 days when unknown) are left out. The caller leaves
/// adult channels out. Answers how many channels and programmes went in, and
/// the file's size.
pub fn save(path: &Path, channels: &[ToSave], now: DateTime<Utc>) -> std::io::Result<(usize, usize, u64)> {
    let mut programmes = 0;
    let channels: Vec<CachedChannel> = channels
        .iter()
        .map(|c| {
            let days = if c.archive_days == 0 {
                14
            } else {
                i64::from(c.archive_days) + 1
            };
            let oldest = now - Duration::days(days);
            let entries: Vec<(i64, i64, String, Option<u8>)> = c
                .epg
                .entries()
                .iter()
                .filter(|e| e.end > oldest)
                .map(|e| {
                    (
                        e.start.timestamp(),
                        e.end.timestamp(),
                        e.title.clone(),
                        e.has_archive.map(u8::from),
                    )
                })
                .collect();
            programmes += entries.len();
            CachedChannel {
                id: c.id,
                fetched_at: c.epg.fetched_at.timestamp(),
                entries,
            }
        })
        .collect();
    let count = channels.len();
    let bytes = serde_json::to_vec(&CacheFile {
        version: VERSION,
        channels,
    })
    .map_err(std::io::Error::other)?;
    if let Some(dir) = path.parent() {
        std::fs::create_dir_all(dir)?;
    }
    let tmp = path.with_extension("json.tmp");
    std::fs::write(&tmp, &bytes)?;
    std::fs::rename(&tmp, path)?;
    Ok((count, programmes, bytes.len() as u64))
}

/// What the file holds: per catch-up id, the EPG as it was fetched then. A
/// missing file is an empty cache; a broken one, or one of another version,
/// an error (the caller logs it and writes a new one in time).
pub fn load(path: &Path) -> Result<Vec<(i64, ChannelEpg)>, String> {
    let bytes = match std::fs::read(path) {
        Ok(b) => b,
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => return Ok(Vec::new()),
        Err(e) => return Err(e.to_string()),
    };
    let file: CacheFile = serde_json::from_slice(&bytes).map_err(|e| e.to_string())?;
    if file.version != VERSION {
        return Err(format!("version {}", file.version));
    }
    Ok(file
        .channels
        .into_iter()
        .filter_map(|c| {
            let fetched_at = Utc.timestamp_opt(c.fetched_at, 0).single()?;
            let entries = c
                .entries
                .into_iter()
                .filter_map(|(start, end, title, kept)| {
                    Some(EpgEntry {
                        title,
                        start: Utc.timestamp_opt(start, 0).single()?,
                        end: Utc.timestamp_opt(end, 0).single()?,
                        has_archive: kept.map(|k| k != 0),
                    })
                })
                .collect();
            Some((c.id, ChannelEpg::new(Epg::new(entries), fetched_at)))
        })
        .collect())
}
```

```rust
//! Channel logos for the guide's column headers: fetched only for the columns
//! on screen, kept as files, decoded (PNG only), made small and uploaded once
//! as textures. Draws nothing itself.

use parking_lot::Mutex;
use std::collections::HashMap;
use std::path::{Path, PathBuf};
use std::sync::Arc;
use std::time::Duration;

/// Logos are made to fit this box (width, height in pixels).
pub const LOGO_BOX: [u32; 2] = [128, 48];
/// A logo bigger than this is no logo.
const MAX_BYTES: usize = 512 * 1024;
/// Logos fetched at the same time.
const AT_ONCE: usize = 2;

enum Slot {
    /// Being fetched and decoded.
    Loading,
    /// Decoded, not uploaded yet.
    Decoded(egui::ColorImage),
    Ready(egui::TextureHandle),
    /// No logo: the header shows the name. Not tried again this session.
    Missing,
}

pub struct LogoStore {
    dir: PathBuf,
    client: reqwest::Client,
    slots: HashMap<String, Slot>,
    loading: usize,
    done: Arc<Mutex<Vec<(String, Option<egui::ColorImage>)>>>,
}

impl LogoStore {
    /// Logos kept as files in `dir`.
    pub fn new(dir: PathBuf) -> Self {
        let client = reqwest::Client::builder()
            .timeout(Duration::from_secs(10))
            .user_agent(crate::APP_ID)
            .build()
            .unwrap_or_default();
        Self {
            dir,
            client,
            slots: HashMap::new(),
            loading: 0,
            done: Arc::new(Mutex::new(Vec::new())),
        }
    }

    /// The texture of `url`'s logo once it is there. A URL not seen before is
    /// asked for (at most two at a time; the others are asked for in a later
    /// frame). `None` while loading, and for no logo.
    pub fn texture(&mut self, ctx: &egui::Context, url: &str) -> Option<&egui::TextureHandle> {
        if !self.slots.contains_key(url) {
            if self.loading < AT_ONCE {
                self.request(url);
            }
            return None;
        }
        if matches!(self.slots.get(url), Some(Slot::Decoded(_))) {
            if let Some(Slot::Decoded(image)) = self.slots.remove(url) {
                let texture =
                    ctx.load_texture(format!("logo {url}"), image, egui::TextureOptions::LINEAR);
                self.slots.insert(url.to_owned(), Slot::Ready(texture));
            }
        }
        match self.slots.get(url) {
            Some(Slot::Ready(texture)) => Some(texture),
            _ => None,
        }
    }

    /// Whether `url`'s logo is still on its way (the header shows a dot).
    pub fn is_loading(&self, url: &str) -> bool {
        matches!(self.slots.get(url), Some(Slot::Loading))
    }

    /// Takes in the logos that came; once per frame.
    pub fn drain(&mut self) {
        for (url, image) in std::mem::take(&mut *self.done.lock()) {
            self.loading = self.loading.saturating_sub(1);
            self.slots
                .insert(url, image.map_or(Slot::Missing, Slot::Decoded));
        }
    }

    fn request(&mut self, url: &str) {
        self.slots.insert(url.to_owned(), Slot::Loading);
        self.loading += 1;
        let url = url.to_owned();
        let file = self.dir.join(file_name(&url));
        let (client, done) = (self.client.clone(), self.done.clone());
        tokio::spawn(async move {
            let image = load_logo(&client, &url, &file).await;
            done.lock().push((url, image));
        });
    }
}

/// The logo from its file, else from the web (then kept as a file); decoded
/// and made small. `None` when there is none to show.
async fn load_logo(client: &reqwest::Client, url: &str, file: &Path) -> Option<egui::ColorImage> {
    let host = host_of(url);
    let bytes = match std::fs::read(file) {
        Ok(bytes) => bytes,
        Err(_) => {
            let Some(bytes) = download(client, url).await else {
                tracing::info!("logo: {host} could not be fetched - the name shows");
                return None;
            };
            if let Some(dir) = file.parent() {
                let _ = std::fs::create_dir_all(dir);
            }
            let _ = std::fs::write(file, &bytes);
            bytes
        }
    };
    let image = decode(&bytes);
    match &image {
        Some(i) => tracing::info!("logo: {host} ready ({}x{})", i.size[0], i.size[1]),
        None => tracing::info!("logo: {host} is no PNG - the name shows"),
    }
    image
}

/// `url`'s body, at most [`MAX_BYTES`]; `None` on an error status, a failure,
/// or more.
async fn download(client: &reqwest::Client, url: &str) -> Option<Vec<u8>> {
    let mut response = client.get(url).send().await.ok()?;
    if !response.status().is_success() {
        return None;
    }
    let mut bytes = Vec::new();
    while let Some(chunk) = response.chunk().await.ok()? {
        bytes.extend_from_slice(&chunk);
        if bytes.len() > MAX_BYTES {
            return None;
        }
    }
    Some(bytes)
}

/// A PNG made to fit [`LOGO_BOX`]; `None` for anything else.
pub fn decode(bytes: &[u8]) -> Option<egui::ColorImage> {
    if !bytes.starts_with(b"\x89PNG\r\n\x1a\n") {
        return None;
    }
    let image = image::load_from_memory_with_format(bytes, image::ImageFormat::Png).ok()?;
    let small = image.thumbnail(LOGO_BOX[0], LOGO_BOX[1]).to_rgba8();
    let size = [small.width() as usize, small.height() as usize];
    Some(egui::ColorImage::from_rgba_unmultiplied(size, small.as_raw()))
}

/// The file a logo is kept in: 16 hex digits of its URL's SHA-256.
pub fn file_name(url: &str) -> String {
    let digest = ring::digest::digest(&ring::digest::SHA256, url.as_bytes());
    let hex: String = digest.as_ref()[..8]
        .iter()
        .map(|b| format!("{b:02x}"))
        .collect();
    format!("{hex}.img")
}

/// The host (and port) of a URL, for the log: a logo URL may carry a token.
pub fn host_of(url: &str) -> &str {
    let rest = url.split_once("://").map_or(url, |(_, rest)| rest);
    let authority = rest.split(['/', '?', '#']).next().unwrap_or("");
    authority.rsplit('@').next().unwrap_or("")
}
```

```rust
//! The guide (`g`): one column per channel with catch-up, live and catch-up in
//! one list, NLZIET style. `GuideView` keeps the guide's state for the whole
//! session; `show` draws one frame and hands what the user did to app.rs as a
//! [`GuideAction`], as settings_ui.rs does.

use crate::catalog::GuideChannel;
use crate::epg::EpgEntry;
use crate::guide::store::{filter_channels, EpgStore, FilterResult};
use crate::guide::time::{self, Playable};
use chrono::{DateTime, NaiveDate, Utc};
use std::collections::{HashMap, HashSet};
use std::ops::Range;

/// Where the now-line sits, as a share of a column's rows from the top.
const NOW_LINE: f32 = 0.35;

/// Nu & straks, or Primetime (19:00 on the chosen day).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Mode {
    NowAndNext,
    Primetime,
}

/// What the user did in the guide.
#[derive(Debug, Clone, PartialEq)]
pub enum GuideAction {
    /// Enter, or a click on a programme: app.rs plays it, or says why not.
    Play {
        channel: GuideChannel,
        entry: EpgEntry,
        playable: Playable,
    },
    Close,
    Help,
}

/// ↑ ↓ Home End in a column.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum RowStep {
    Up,
    Down,
    First,
    Last,
}

/// What one frame of the guide looks at: worked out at the top of `show`, and
/// what keys, wheel and clicks act on.
pub struct Page<'a> {
    pub channels: &'a [GuideChannel],
    pub store: &'a EpgStore,
    /// Indices into `channels` of the ones shown: all, or what the filter left.
    pub shown: &'a [usize],
    /// Columns side by side, and rows in a column.
    pub cols: usize,
    pub rows: usize,
    pub now: DateTime<Utc>,
    pub today: NaiveDate,
}

impl Page<'_> {
    /// The row of the now-line.
    pub fn line(&self) -> usize {
        (self.rows as f32 * NOW_LINE) as usize
    }

    /// The channel in column `col` of a page that starts at shown index `start`.
    pub fn channel(&self, start: usize, col: usize) -> Option<&GuideChannel> {
        self.shown
            .get(start + col)
            .and_then(|&i| self.channels.get(i))
    }
}

/// What a filter result was worked out for.
#[derive(Debug, Clone, PartialEq, Eq)]
struct FilterKey {
    text: String,
    day: NaiveDate,
    store_revision: u64,
    channels_revision: u64,
}

/// The guide's state, kept for the whole session: it opens as it was left.
pub struct GuideView {
    day: NaiveDate,
    mode: Mode,
    /// Index into the shown channels of the leftmost column.
    page_start: usize,
    /// The cursor's column, counted within the page.
    selected: usize,
    /// Per catch-up id: the programme the cursor is on (an index into its EPG).
    cursor: HashMap<i64, usize>,
    /// Per catch-up id: the entry in the top row, fractional while the wheel
    /// turns; before the day's first programme the rows stay empty.
    top: HashMap<i64, f32>,
    /// Columns lined up since the last `realign`; the others line up as soon
    /// as they show with programmes on the day.
    aligned: HashSet<i64>,
    filter: String,
    filtered: Option<(FilterKey, FilterResult)>,
    /// The date list while it is open: the day it highlights.
    date_pick: Option<NaiveDate>,
}

impl GuideView {
    pub fn new(today: NaiveDate) -> Self {
        Self {
            day: today,
            mode: Mode::NowAndNext,
            page_start: 0,
            selected: 0,
            cursor: HashMap::new(),
            top: HashMap::new(),
            aligned: HashSet::new(),
            filter: String::new(),
            filtered: None,
            date_pick: None,
        }
    }

    /// The guide opens: in Nu & straks it lines up on now (today) again; the
    /// rest is as it was left.
    pub fn opened(&mut self, today: NaiveDate) {
        self.date_pick = None;
        if self.mode == Mode::NowAndNext {
            self.day = today;
            self.realign();
        }
    }

    /// Every column lines up again as soon as it shows with programmes.
    pub fn realign(&mut self) {
        self.aligned.clear();
    }

    /// `n`, or a click on "Nu & straks": today, lined up on now.
    pub fn now_and_next(&mut self, today: NaiveDate) {
        self.mode = Mode::NowAndNext;
        self.day = today;
        self.realign();
        tracing::info!("guide: now and next");
    }

    /// `p`, or a click on "Primetime": 19:00 on the chosen day.
    pub fn primetime(&mut self) {
        self.mode = Mode::Primetime;
        self.realign();
        tracing::info!("guide: primetime on {}", self.day);
    }

    /// A day from the date list: its primetime.
    pub fn pick_day(&mut self, day: NaiveDate) {
        self.day = day;
        self.date_pick = None;
        self.primetime();
    }

    /// In Nu & straks the guide follows today past midnight.
    pub fn follow_today(&mut self, today: NaiveDate) {
        if self.mode == Mode::NowAndNext && self.day != today {
            self.day = today;
            self.realign();
        }
    }

    /// `d`, or a click on the date: the list opens on the chosen day.
    pub fn open_dates(&mut self) {
        self.date_pick = Some(self.day);
    }

    /// ↑ or ↓ in the date list (`days` in order, the earliest first).
    pub fn move_date(&mut self, days: &[NaiveDate], later: bool) {
        let Some(current) = self.date_pick else {
            return;
        };
        let i = days.iter().position(|d| *d == current).unwrap_or(0);
        let j = if later {
            (i + 1).min(days.len().saturating_sub(1))
        } else {
            i.saturating_sub(1)
        };
        if let Some(day) = days.get(j) {
            self.date_pick = Some(*day);
        }
    }

    /// The moment the columns line up on.
    fn target_time(&self, now: DateTime<Utc>) -> DateTime<Utc> {
        match self.mode {
            Mode::NowAndNext => now,
            Mode::Primetime => time::at_hour(self.day, time::PRIMETIME_HOUR),
        }
    }

    /// Works the filter's result out again when its text, the day, the store or
    /// the channel list changed. They are compared where they lie, so a frame
    /// in which nothing changed allocates nothing. No filter: no result.
    pub fn refresh_filter(
        &mut self,
        channels: &[GuideChannel],
        store: &EpgStore,
        channels_revision: u64,
    ) {
        if self.filter.trim().is_empty() {
            self.filtered = None;
            return;
        }
        let fresh = self.filtered.as_ref().is_some_and(|(key, _)| {
            key.text == self.filter
                && key.day == self.day
                && key.store_revision == store.revision()
                && key.channels_revision == channels_revision
        });
        if fresh {
            return;
        }
        let day = self.day;
        let result = filter_channels(channels, store, &self.filter, |e| time::day_slice(e, day));
        let key = FilterKey {
            text: self.filter.clone(),
            day,
            store_revision: store.revision(),
            channels_revision,
        };
        self.filtered = Some((key, result));
    }

    /// The filter's result, while a filter is set.
    pub fn filtered(&self) -> Option<&FilterResult> {
        self.filtered.as_ref().map(|(_, result)| result)
    }

    /// Lines up every column of the page that has programmes on the day and
    /// was not lined up since the last `realign`: its cursor goes to the target
    /// (now, 19:00, or the filter's next match) and that row to the now-line. A
    /// column whose EPG comes later lines up when it comes.
    pub fn align(&mut self, page: &Page, matches: Option<&HashMap<i64, Vec<usize>>>) {
        let t = self.target_time(page.now);
        for col in 0..page.cols {
            let Some(ch) = page.channel(self.page_start, col) else {
                break;
            };
            let id = ch.archive_id;
            if self.aligned.contains(&id) {
                continue;
            }
            let Some(epg) = page.store.get(id) else {
                continue;
            };
            let entries = epg.entries();
            let target = match matches.and_then(|m| m.get(&id)) {
                Some(hits) => time::match_target(entries, hits, t),
                None => time::target_index(entries, time::day_slice(entries, self.day), t),
            };
            let Some(target) = target else {
                continue;
            };
            self.cursor.insert(id, target);
            self.top.insert(id, target as f32 - page.line() as f32);
            self.aligned.insert(id);
        }
    }

    /// Keeps the page and the cursor's column within the shown channels, which
    /// change under the guide with the filter, the lock or the catalog.
    pub fn clamp(&mut self, page: &Page) {
        let n = page.shown.len();
        self.page_start = self.page_start.min(n.saturating_sub(page.cols));
        let on_page = n.saturating_sub(self.page_start).min(page.cols);
        self.selected = self.selected.min(on_page.saturating_sub(1));
    }

    /// ← or →: the next column; at the edge the page moves one column.
    pub fn move_column(&mut self, page: &Page, right: bool) {
        let n = page.shown.len();
        if right {
            if self.selected + 1 < page.cols && self.page_start + self.selected + 1 < n {
                self.selected += 1;
            } else if self.page_start + page.cols < n {
                self.page_start += 1;
            }
        } else if self.selected > 0 {
            self.selected -= 1;
        } else if self.page_start > 0 {
            self.page_start -= 1;
        }
    }

    /// PgUp or PgDn, ‹ or ›: a page of channels, never past the last full page.
    pub fn move_page(&mut self, page: &Page, forward: bool) {
        let last = page.shown.len().saturating_sub(page.cols);
        self.page_start = if forward {
            (self.page_start + page.cols).min(last)
        } else {
            self.page_start.saturating_sub(page.cols)
        };
    }

    /// ↑ ↓ Home End in the cursor's column, within the day; the column scrolls
    /// along so the cursor stays in view.
    pub fn move_row(&mut self, page: &Page, step: RowStep) {
        let Some(ch) = page.channel(self.page_start, self.selected) else {
            return;
        };
        let id = ch.archive_id;
        let Some(epg) = page.store.get(id) else {
            return;
        };
        let range = time::day_slice(epg.entries(), self.day);
        if range.is_empty() {
            return;
        }
        let last = range.end - 1;
        let current = self
            .cursor
            .get(&id)
            .copied()
            .unwrap_or(range.start)
            .clamp(range.start, last);
        let next = match step {
            RowStep::Up => current.saturating_sub(1).max(range.start),
            RowStep::Down => (current + 1).min(last),
            RowStep::First => range.start,
            RowStep::Last => last,
        };
        self.cursor.insert(id, next);
        let rows = page.rows.max(1) as f32;
        let top = self.top_of(id, &range, page);
        let wanted = if (next as f32) < top {
            next as f32
        } else if next as f32 > top + rows - 1.0 {
            next as f32 - rows + 1.0
        } else {
            top
        };
        self.top.insert(id, clamp_top(wanted, &range, page));
    }

    /// The wheel over column `col`: `rows` rows later (or earlier, negative).
    pub fn scroll(&mut self, page: &Page, col: usize, rows: f32) {
        let Some(ch) = page.channel(self.page_start, col) else {
            return;
        };
        let id = ch.archive_id;
        let Some(epg) = page.store.get(id) else {
            return;
        };
        let range = time::day_slice(epg.entries(), self.day);
        if range.is_empty() {
            return;
        }
        let top = self.top_of(id, &range, page) + rows;
        self.top.insert(id, clamp_top(top, &range, page));
    }

    /// A column's top row: as kept, else the day's first programme on the
    /// now-line.
    pub fn top_of(&self, id: i64, range: &Range<usize>, page: &Page) -> f32 {
        self.top
            .get(&id)
            .copied()
            .unwrap_or(range.start as f32 - page.line() as f32)
    }

    /// The programme under the cursor, to play.
    pub fn play_selected(&self, page: &Page) -> Option<GuideAction> {
        let ch = page.channel(self.page_start, self.selected)?;
        let i = *self.cursor.get(&ch.archive_id)?;
        let epg = page.store.get(ch.archive_id)?;
        if !time::day_slice(epg.entries(), self.day).contains(&i) {
            return None;
        }
        self.play(page, ch, i)
    }

    /// Programme `i` of `ch`, to play.
    pub fn play(&self, page: &Page, ch: &GuideChannel, i: usize) -> Option<GuideAction> {
        let epg = page.store.get(ch.archive_id)?;
        let entry = epg.entries().get(i)?.clone();
        let playable = time::playable(&entry, ch.archive_days, epg.trusts_archive_flag, page.now);
        Some(GuideAction::Play {
            channel: ch.clone(),
            entry,
            playable,
        })
    }

    /// Esc: closes the date list; else wipes the filter; else closes the guide.
    pub fn escape(&mut self) -> Option<GuideAction> {
        if self.date_pick.take().is_some() {
            return None;
        }
        if !self.filter.is_empty() {
            self.filter.clear();
            self.realign();
            return None;
        }
        Some(GuideAction::Close)
    }
}

/// A column's top row, kept so the day's first programme never sinks below
/// the now-line and its last never rises above it.
fn clamp_top(top: f32, range: &Range<usize>, page: &Page) -> f32 {
    let line = page.line() as f32;
    let min = range.start as f32 - line;
    let max = (range.end as f32 - 1.0 - line).max(min);
    top.clamp(min, max)
}
```

```rust
const PANEL_HOVER: Color32 = Color32::from_rgb(44, 44, 54);
const ROW_BG: Color32 = Color32::from_rgb(22, 22, 28);
const ROW_HOVER: Color32 = Color32::from_rgb(30, 30, 38);
const ROW_LIVE: Color32 = Color32::from_rgb(28, 58, 30);
const ROW_LIVE_HOVER: Color32 = Color32::from_rgb(34, 70, 38);
const ROW_SELECTED: Color32 = Color32::from_rgb(40, 55, 80);
const ACCENT: Color32 = Color32::from_rgb(255, 80, 140);
const LIVE_GREEN: Color32 = Color32::from_rgb(120, 230, 100);
const REPLAY_BLUE: Color32 = Color32::from_rgb(140, 180, 220);
const MATCH_YELLOW: Color32 = Color32::from_rgb(230, 220, 110);

/// What the guide shows but app.rs owns.
pub struct GuideData<'a> {
    pub lang: Lang,
    pub channels: &'a [GuideChannel],
    /// Counts every new channel list (catalog, lock): what is worked out from
    /// the list is worked out again when it moves.
    pub channels_revision: u64,
    pub store: &'a EpgStore,
    /// Catch-up ids whose EPG is being fetched: their header shows a dot.
    pub fetching: &'a HashSet<i64>,
    /// What plays, for "playing: …" in the top bar.
    pub playing: Option<&'a str>,
    pub now: DateTime<Utc>,
    pub today: NaiveDate,
    /// The guide reads the keyboard (not while the help is over it).
    pub keys: bool,
}

/// The keys of one frame, as the guide uses them.
struct Keys {
    left: bool,
    right: bool,
    up: bool,
    down: bool,
    page_up: bool,
    page_down: bool,
    home: bool,
    end: bool,
    enter: bool,
    esc: bool,
    now_next: bool,
    primetime: bool,
    dates: bool,
    filter: bool,
    close: bool,
    help: bool,
}

fn read_keys(ctx: &egui::Context) -> Keys {
    ctx.input(|i| Keys {
        left: i.key_pressed(Key::ArrowLeft),
        right: i.key_pressed(Key::ArrowRight),
        up: i.key_pressed(Key::ArrowUp),
        down: i.key_pressed(Key::ArrowDown),
        page_up: i.key_pressed(Key::PageUp),
        page_down: i.key_pressed(Key::PageDown),
        home: i.key_pressed(Key::Home),
        end: i.key_pressed(Key::End),
        enter: i.key_pressed(Key::Enter),
        esc: i.key_pressed(Key::Escape),
        now_next: i.key_pressed(Key::N),
        primetime: i.key_pressed(Key::P),
        dates: i.key_pressed(Key::D),
        filter: i.key_pressed(Key::F),
        close: i.key_pressed(Key::G),
        help: i
            .events
            .iter()
            .any(|e| matches!(e, egui::Event::Text(t) if t == "?")),
    })
}

/// Texts that change now and then: made when they change, not per frame.
#[derive(Default)]
struct Labels {
    day: Option<(NaiveDate, NaiveDate, Lang, String)>,
    range: Option<((usize, usize, usize, Lang), String)>,
    playing: Option<(String, Lang, String)>,
}

impl Labels {
    fn day(&mut self, lang: Lang, day: NaiveDate, today: NaiveDate) -> &str {
        if !matches!(&self.day, Some((d, t, l, _)) if *d == day && *t == today && *l == lang) {
            self.day = Some((day, today, lang, i18n::day_label(lang, day, today)));
        }
        self.day.as_ref().map_or("", |(_, _, _, s)| s.as_str())
    }

    fn range(&mut self, lang: Lang, from: usize, to: usize, of: usize) -> &str {
        let key = (from, to, of, lang);
        if !matches!(&self.range, Some((k, _)) if *k == key) {
            let text = i18n::tr(
                lang,
                T::GuideChannelsRange,
                &[&from.to_string(), &to.to_string(), &of.to_string()],
            );
            self.range = Some((key, text));
        }
        self.range.as_ref().map_or("", |(_, s)| s.as_str())
    }

    fn playing(&mut self, lang: Lang, what: &str) -> &str {
        if !matches!(&self.playing, Some((w, l, _)) if w == what && *l == lang) {
            let text = i18n::tr(lang, T::GuidePlaying, &[what]);
            self.playing = Some((what.to_owned(), lang, text));
        }
        self.playing.as_ref().map_or("", |(_, _, s)| s.as_str())
    }
}

/// Where the top bar's parts go in a bar `bar`; it narrows down to the 640 px
/// minimum window.
struct TopBar {
    date: Rect,
    modes: Rect,
    filter: Rect,
    info: Rect,
    prev: Rect,
    next: Rect,
}

impl TopBar {
    fn new(bar: Rect) -> Self {
        let narrow = bar.width() < 900.0;
        let h = 36.0;
        let y = bar.center().y - h / 2.0;
        let at = |x: f32, w: f32| Rect::from_min_size(Pos2::new(x, y), Vec2::new(w, h));
        let (date_w, modes_w, filter_w) = if narrow {
            (120.0, 190.0, 150.0)
        } else {
            (160.0, 250.0, 240.0)
        };
        let date = at(bar.left() + MARGIN, date_w);
        let modes = at(date.right() + 10.0, modes_w);
        let filter = at(modes.right() + 10.0, filter_w);
        let next = at(bar.right() - MARGIN - h, h);
        let prev = at(next.left() - 6.0 - h, h);
        let info = Rect::from_min_max(
            Pos2::new(filter.right() + 14.0, y),
            Pos2::new((prev.left() - 12.0).max(filter.right() + 14.0), y + h),
        );
        Self {
            date,
            modes,
            filter,
            info,
            prev,
            next,
        }
    }
}

impl GuideView {
    /// Index into the guide's channel list of the leftmost column, and how many
    /// columns show: where the fetcher starts.
    pub fn visible_window(&self) -> (usize, usize) {
        self.visible
    }

    /// One frame of the guide over the whole window. Per frame it works only on
    /// the visible rows of the visible columns.
    pub fn show(
        &mut self,
        ctx: &egui::Context,
        data: &GuideData,
        logos: &mut LogoStore,
    ) -> Option<GuideAction> {
        let screen = ctx.screen_rect();
        let cols = (((screen.width() - 2.0 * MARGIN + COLUMN_GAP) / (COLUMN_W + COLUMN_GAP))
            as usize)
            .clamp(1, 10);
        let area = Rect::from_min_max(
            Pos2::new(screen.left(), screen.top() + TOP_BAR_H),
            Pos2::new(screen.right(), screen.bottom() - FOOTER_H),
        );
        let rows = ((area.height() - HEADER_H) / ROW_H).floor().max(1.0) as usize;
        let bar = TopBar::new(Rect::from_min_size(
            screen.min,
            Vec2::new(screen.width(), TOP_BAR_H),
        ));

        self.follow_today(data.today);
        if self.all_for != Some(data.channels_revision) || self.all.len() != data.channels.len() {
            self.all = (0..data.channels.len()).collect();
            self.all_for = Some(data.channels_revision);
        }
        self.refresh_filter(data.channels, data.store, data.channels_revision);
        // Out of `self` for this frame, so the page can borrow them while `self`
        // changes; moving a Vec allocates nothing.
        let filtered = self.filtered.take();
        let all = std::mem::take(&mut self.all);
        let (shown, matches) = match &filtered {
            Some((_, result)) => (&result.channels[..], Some(&result.matches)),
            None => (&all[..], None),
        };
        let page = Page {
            channels: data.channels,
            store: data.store,
            shown,
            cols,
            rows,
            now: data.now,
            today: data.today,
        };
        self.clamp(&page);

        let mut action = None;
        let keys = read_keys(ctx);
        let focused = ctx.memory(|m| m.has_focus(filter_id()));
        if data.keys && !focused && !self.filter_had_focus {
            action = self.keys(ctx, &keys, &page);
        } else if focused && keys.down {
            ctx.memory_mut(|m| m.surrender_focus(filter_id()));
        }
        self.clamp(&page);
        if self.date_pick.is_some() {
            self.refresh_days(data);
        }
        self.align(&page, matches);
        let on_page = page.shown.len().saturating_sub(self.page_start).min(cols);
        self.visible = (page.shown.get(self.page_start).copied().unwrap_or(0), on_page);

        egui::CentralPanel::default()
            .frame(egui::Frame::none().fill(BG))
            .show(ctx, |ui| {
                self.top_bar(ui, data, &page, &bar);
                if let Some(a) = self.columns(ui, data, &page, matches, logos, area) {
                    action = Some(a);
                }
                ui.painter().text(
                    Pos2::new(screen.right() - MARGIN, screen.bottom() - FOOTER_H / 2.0),
                    Align2::RIGHT_CENTER,
                    i18n::t(data.lang, T::GuideKeysFooter),
                    FontId::proportional(11.0),
                    Color32::from_white_alpha(95),
                );
            });
        if self.date_pick.is_some() {
            self.date_list(ctx, data, bar.date);
        }
        self.filter_had_focus = ctx.memory(|m| m.has_focus(filter_id()));
        self.filtered = filtered;
        self.all = all;
        action
    }

    /// The keyboard, while the filter box does not have it.
    fn keys(&mut self, ctx: &egui::Context, k: &Keys, page: &Page) -> Option<GuideAction> {
        if self.date_pick.is_some() {
            let days = std::mem::take(&mut self.days);
            if k.up {
                self.move_date(&days, false);
            }
            if k.down {
                self.move_date(&days, true);
            }
            self.days = days;
            if k.enter {
                if let Some(day) = self.date_pick {
                    self.pick_day(day);
                }
            }
            if k.esc {
                self.date_pick = None;
            }
            return k.close.then_some(GuideAction::Close);
        }
        if k.help {
            return Some(GuideAction::Help);
        }
        if k.esc {
            return self.escape();
        }
        if k.close {
            return Some(GuideAction::Close);
        }
        if k.filter {
            // The f puts the keyboard in the box; it is no letter typed into it.
            ctx.input_mut(|i| {
                i.events
                    .retain(|e| !matches!(e, egui::Event::Text(t) if t.eq_ignore_ascii_case("f")))
            });
            ctx.memory_mut(|m| m.request_focus(filter_id()));
            self.filter_wanted = true;
            return None;
        }
        if k.now_next {
            self.now_and_next(page.today);
        }
        if k.primetime {
            self.primetime();
        }
        if k.dates {
            self.open_dates();
        }
        if k.left {
            self.move_column(page, false);
        }
        if k.right {
            self.move_column(page, true);
        }
        if k.page_up {
            self.move_page(page, false);
        }
        if k.page_down {
            self.move_page(page, true);
        }
        if k.up {
            self.move_row(page, RowStep::Up);
        }
        if k.down {
            self.move_row(page, RowStep::Down);
        }
        if k.home {
            self.move_row(page, RowStep::First);
        }
        if k.end {
            self.move_row(page, RowStep::Last);
        }
        if k.enter {
            return self.play_selected(page);
        }
        None
    }

    /// The date list's days, worked out again when the store, the channels or
    /// the day changed.
    fn refresh_days(&mut self, data: &GuideData) {
        let key = (data.store.revision(), data.channels_revision, data.today);
        if self.days_for == Some(key) {
            return;
        }
        let back = data.channels.iter().map(|c| c.archive_days).max().unwrap_or(0);
        self.days = time::date_range(data.today, back, data.store.last_day(time::day_of));
        self.days_for = Some(key);
    }

    fn top_bar(&mut self, ui: &mut egui::Ui, data: &GuideData, page: &Page, bar: &TopBar) {
        let lang = data.lang;
        // The date.
        let date = ui.interact(bar.date, egui::Id::new("__guide_date__"), CLICK);
        {
            let p = ui.painter();
            let fill = if date.hovered() { PANEL_HOVER } else { PANEL };
            p.rect_filled(bar.date, 6.0, fill);
            p.text(
                bar.date.left_center() + Vec2::new(14.0, 0.0),
                Align2::LEFT_CENTER,
                self.labels.day(lang, self.day, data.today),
                FontId::proportional(15.0),
                Color32::WHITE,
            );
            chevron_down(p, bar.date.right_center() - Vec2::new(16.0, 0.0));
        }
        if date.clicked() {
            if self.date_pick.is_some() {
                self.date_pick = None;
            } else {
                self.open_dates();
            }
        }
        // Nu & straks | Primetime.
        ui.painter().rect_filled(bar.modes, 6.0, PANEL);
        let mid = bar.modes.center().x;
        let now_half = Rect::from_min_max(bar.modes.min, Pos2::new(mid, bar.modes.max.y));
        let prime_half = Rect::from_min_max(Pos2::new(mid, bar.modes.min.y), bar.modes.max);
        let now_text = i18n::t(lang, T::GuideNow);
        if segment(ui, now_half, "__guide_now__", now_text, self.mode == Mode::NowAndNext).clicked() {
            self.now_and_next(data.today);
        }
        let prime_text = i18n::t(lang, T::GuidePrime);
        if segment(ui, prime_half, "__guide_prime__", prime_text, self.mode == Mode::Primetime).clicked() {
            self.primetime();
        }
        // The filter box: the keyboard gets there by `f` or a click only, and
        // not at all while the help is over the guide.
        let edit = egui::TextEdit::singleline(&mut self.filter)
            .id(filter_id())
            .hint_text(i18n::t(lang, T::GuideFilterHint))
            .font(FontId::proportional(15.0))
            .desired_width(bar.filter.width() - 16.0);
        let response = ui
            .allocate_ui_at_rect(bar.filter, |ui| ui.add_enabled(data.keys, edit))
            .inner;
        if response.clicked() {
            self.filter_wanted = true;
        }
        if response.gained_focus() && !self.filter_wanted {
            response.surrender_focus();
        }
        if response.lost_focus() {
            self.filter_wanted = false;
        }
        if response.changed() {
            self.realign();
        }
        // ‹ › a page of channels.
        if chevron_button(ui, bar.prev, "__guide_prev__", false).clicked() {
            self.move_page(page, false);
        }
        if chevron_button(ui, bar.next, "__guide_next__", true).clicked() {
            self.move_page(page, true);
        }
        // Which channels show, and what plays.
        if bar.info.width() > 90.0 && !page.shown.is_empty() {
            let from = self.page_start + 1;
            let to = (self.page_start + page.cols).min(page.shown.len());
            ui.painter().text(
                bar.info.right_center(),
                Align2::RIGHT_CENTER,
                self.labels.range(lang, from, to, page.shown.len()),
                FontId::proportional(12.0),
                Color32::from_white_alpha(150),
            );
            let room = bar.info.width() - 180.0;
            if let (Some(what), true) = (data.playing, room > 60.0) {
                let text = self.labels.playing(lang, what);
                let p = ui.painter();
                let galley = p.layout_job(single_line(text, FontId::proportional(12.0), LIVE_GREEN, room));
                let at = Pos2::new(bar.info.left(), bar.info.center().y - galley.size().y / 2.0);
                p.galley(at, galley, LIVE_GREEN);
            }
        }
    }

    #[allow(clippy::too_many_arguments)]
    fn columns(
        &mut self,
        ui: &egui::Ui,
        data: &GuideData,
        page: &Page,
        matches: Option<&HashMap<i64, Vec<usize>>>,
        logos: &mut LogoStore,
        area: Rect,
    ) -> Option<GuideAction> {
        if page.shown.is_empty() {
            let at = Pos2::new(area.center().x, area.top() + 80.0);
            let (font, color) = (FontId::proportional(16.0), Color32::from_white_alpha(140));
            let p = ui.painter();
            if data.channels.is_empty() {
                p.text(at, Align2::CENTER_CENTER, i18n::t(data.lang, T::GuideNoChannels), font, color);
            } else {
                let message = i18n::tr(data.lang, T::GuideNothingFound, &[self.filter.trim()]);
                p.text(at, Align2::CENTER_CENTER, message, font, color);
            }
            return None;
        }
        let (hover, wheel) = ui
            .ctx()
            .input(|i| (i.pointer.hover_pos(), i.raw_scroll_delta.y));
        let live_label = i18n::t(data.lang, T::GuideLiveBadge);
        let mut action = None;
        for col in 0..page.cols {
            let Some(ch) = page.channel(self.page_start, col) else {
                break;
            };
            let left = area.left() + MARGIN + col as f32 * (COLUMN_W + COLUMN_GAP);
            let column = Rect::from_min_max(
                Pos2::new(left, area.top()),
                Pos2::new(left + COLUMN_W, area.bottom()),
            );
            let loading = data.fetching.contains(&ch.archive_id)
                || ch.logo.as_deref().is_some_and(|url| logos.is_loading(url));
            paint_header(ui, logos, ch, column, loading);
            let rows = Rect::from_min_max(Pos2::new(left, area.top() + HEADER_H), column.max);
            if wheel != 0.0 && hover.is_some_and(|p| rows.contains(p)) {
                self.scroll(page, col, -wheel / ROW_H);
            }
            if let Some(a) = self.rows(ui, page, matches, col, ch, rows, live_label) {
                action = Some(a);
            }
        }
        action
    }

    /// The visible rows of one column; a click plays the programme.
    #[allow(clippy::too_many_arguments)]
    fn rows(
        &mut self,
        ui: &egui::Ui,
        page: &Page,
        matches: Option<&HashMap<i64, Vec<usize>>>,
        col: usize,
        ch: &GuideChannel,
        area: Rect,
        live_label: &str,
    ) -> Option<GuideAction> {
        let epg = page.store.get(ch.archive_id)?;
        let entries = epg.entries();
        let range = time::day_slice(entries, self.day);
        if range.is_empty() {
            return None;
        }
        let top = self.top_of(ch.archive_id, &range, page);
        let first = top.floor();
        let shift = (top - first) * ROW_H;
        let cursor = if col == self.selected {
            self.cursor.get(&ch.archive_id).copied()
        } else {
            None
        };
        let hits = matches.and_then(|m| m.get(&ch.archive_id));
        let painter = ui.painter().with_clip_rect(area);
        let mut clicked = None;
        for r in 0..=page.rows + 1 {
            let i = first as i64 + r as i64;
            if i < range.start as i64 || i >= range.end as i64 {
                continue;
            }
            let i = i as usize;
            let y = area.top() + r as f32 * ROW_H - shift;
            if y >= area.bottom() {
                break;
            }
            let row = Rect::from_min_size(Pos2::new(area.left(), y), Vec2::new(area.width(), ROW_H - 3.0));
            let entry = &entries[i];
            let playable = time::playable(entry, ch.archive_days, epg.trusts_archive_flag, page.now);
            let id = egui::Id::new(("__guide_row__", ch.archive_id, i));
            let response = ui.interact(row.intersect(area), id, CLICK);
            let look = RowLook {
                playable,
                cursor: cursor == Some(i),
                hovered: response.hovered(),
                hit: hits.is_some_and(|h| h.binary_search(&i).is_ok()),
            };
            paint_row(&painter, row, entry, look, page.now, live_label);
            if response.clicked() {
                clicked = Some(i);
            }
        }
        let i = clicked?;
        self.selected = col;
        self.cursor.insert(ch.archive_id, i);
        self.play(page, ch, i)
    }

    /// The date list under the date button; a click picks a day.
    fn date_list(&mut self, ctx: &egui::Context, data: &GuideData, anchor: Rect) {
        let Some(pick) = self.date_pick else {
            return;
        };
        let n = self.days.len();
        if n == 0 {
            return;
        }
        let i = self.days.iter().position(|d| *d == pick).unwrap_or(0);
        let first = i.saturating_sub(DATE_ROWS / 2).min(n.saturating_sub(DATE_ROWS));
        let count = DATE_ROWS.min(n);
        let mut clicked = None;
        egui::Area::new(egui::Id::new("__guide_dates__"))
            .order(egui::Order::Foreground)
            .sense(Sense::hover())
            .fixed_pos(anchor.left_bottom() + Vec2::new(0.0, 4.0))
            .show(ctx, |ui| {
                let size = Vec2::new(anchor.width(), count as f32 * DATE_ROW_H);
                let (rect, _) = ui.allocate_exact_size(size, Sense::hover());
                let p = ui.painter();
                p.rect_filled(rect, 6.0, PANEL);
                for (k, day) in self.days.iter().enumerate().skip(first).take(count) {
                    let row = Rect::from_min_size(
                        rect.min + Vec2::new(0.0, (k - first) as f32 * DATE_ROW_H),
                        Vec2::new(rect.width(), DATE_ROW_H),
                    );
                    let response = ui.interact(row, egui::Id::new(("__guide_day__", k)), CLICK);
                    if *day == pick || response.hovered() {
                        p.rect_filled(row.shrink(2.0), 4.0, ROW_SELECTED);
                    }
                    let color = if *day == self.day { ACCENT } else { Color32::WHITE };
                    p.text(
                        row.left_center() + Vec2::new(14.0, 0.0),
                        Align2::LEFT_CENTER,
                        i18n::day_label(data.lang, *day, data.today),
                        FontId::proportional(14.0),
                        color,
                    );
                    if response.clicked() {
                        clicked = Some(*day);
                    }
                }
            });
        if let Some(day) = clicked {
            self.pick_day(day);
        }
    }
}

/// How a programme row looks.
struct RowLook {
    playable: Playable,
    cursor: bool,
    hovered: bool,
    /// The title holds the filter's text.
    hit: bool,
}

fn paint_row(
    p: &egui::Painter,
    row: Rect,
    e: &EpgEntry,
    look: RowLook,
    now: DateTime<Utc>,
    live_label: &str,
) {
    let live = look.playable == Playable::Live;
    let fill = match (look.cursor, look.hovered, live) {
        (true, _, _) => ROW_SELECTED,
        (false, true, true) => ROW_LIVE_HOVER,
        (false, true, false) => ROW_HOVER,
        (false, false, true) => ROW_LIVE,
        (false, false, false) => ROW_BG,
    };
    p.rect_filled(row, 4.0, fill);
    if look.cursor {
        p.rect_filled(Rect::from_min_size(row.min, Vec2::new(3.0, row.height())), 0.0, ACCENT);
    }
    let dim = look.playable == Playable::Unavailable;
    let time_color = Color32::from_white_alpha(if dim { 70 } else { 170 });
    let title_color = if look.hit {
        MATCH_YELLOW
    } else if dim {
        Color32::from_white_alpha(95)
    } else {
        Color32::WHITE
    };
    p.text(
        row.left_center() + Vec2::new(10.0, 0.0),
        Align2::LEFT_CENTER,
        crate::epg::hhmm(e.start),
        FontId::monospace(14.0),
        time_color,
    );
    let badge_w = match look.playable {
        Playable::Live => 48.0,
```

```rust
    /// The guide's columns again when the catalog, its loading or the lock
    /// changed; three comparisons otherwise.
    fn refresh_guide_channels(&mut self) {
        let key = (
            self.catalog_generation,
            self.catalog.is_loaded(),
            self.catalog.adult_unlocked(),
        );
        if self.guide_channels_for == Some(key) {
            return;
        }
        self.guide_channels = self.catalog.guide_channels();
        self.guide_channels_for = Some(key);
        self.guide_channels_revision += 1;
    }

    /// `g`: the guide opens as it was left (in Nu & straks: on now). From now on
    /// its EPG is fetched in the background.
    fn open_guide(&mut self) {
        if !self.catalog.is_loaded() {
            self.set_toast(self.t(T::GuideCatalogLoading));
            return;
        }
        self.refresh_guide_channels();
        self.guide_view
            .opened(crate::guide::time::day_of(chrono::Utc::now()));
        self.guide_open = true;
        self.guide_fetching = true;
        tracing::info!("guide: opened ({} channels)", self.guide_channels.len());
    }

    fn close_guide(&mut self) {
        if self.guide_open {
            self.guide_open = false;
            tracing::info!("guide: closed");
        }
    }

    /// Takes the finished EPG fetches in and starts what may start: 2 at a time
    /// with the guide open, 1 with it closed, none while a stream starts.
    fn tick_epg(&mut self) {
        let now = Instant::now();
        let landed = self.epg_fetcher.drain(now);
        let any = !landed.is_empty();
        for fetched in landed {
            if let Ok(epg) = fetched.result {
                self.epg_store
                    .insert(fetched.archive_id, ChannelEpg::new(epg, chrono::Utc::now()));
            }
        }
        if any && self.epg_fetcher.in_flight().is_empty() {
            tracing::info!(
                "guide: epg store {} channels, {} programmes",
                self.epg_store.len(),
                self.epg_store.programmes()
            );
        }
        if !self.guide_fetching {
            return;
        }
        let starting = self
            .stream_starting_since
            .is_some_and(|t| t.elapsed() < Duration::from_secs(10));
        let limit = if starting {
            0
        } else if self.guide_open {
            2
        } else {
            1
        };
        let (start, count) = self.guide_view.visible_window();
        let channels = &self.guide_channels;
        let order =
            fetch_order(start..start + count.max(1), channels.len()).map(|i| channels[i].archive_id);
        self.epg_fetcher
            .tick(&self.epg_store, order, limit, now, chrono::Utc::now());
    }

    /// help it takes no keys; `?` or Esc closes the help.
    fn paint_guide(&mut self, ctx: &egui::Context) {

        if self.show_help {
            let (question, esc) = ctx.input(|i| {
                (
                    i.events
                        .iter()
                        .any(|e| matches!(e, egui::Event::Text(t) if t == "?")),
                    i.key_pressed(Key::Escape),
                )
            });
            if question || esc {

            }
        }

        let data = GuideData {
            lang: self.lang,
            channels: &self.guide_channels,
            channels_revision: self.guide_channels_revision,
            store: &self.epg_store,

    /// A programme picked in the guide: live through the relay, catch-up from
    /// its start on the catch-up twin, or a word on why not.
    fn guide_play(&mut self, channel: GuideChannel, entry: EpgEntry, playable: Playable) {
        let (from, to) = (crate::epg::hhmm(entry.start), crate::epg::hhmm(entry.end));
        match playable {
            Playable::Future => self.set_toast(self.tr(T::GuideStartsAt, &[&from])),
            Playable::Unavailable => self.set_toast(self.t(T::GuideNotReplayable)),
            Playable::Live => {
                tracing::info!(
                    "guide: [LIVE] {} | {} ({} -> {})",
                    channel.name,
                    entry.title,
                    from,
                    to
                );
                let url = self.catalog.portal().live_stream_url(channel.live_id);
                self.load_url(url, true);
                // Up/down continues from this channel.
                self.current_idx = None;
                self.current_stream_id = Some(channel.live_id);
                self.current_name = Some(channel.name.clone());
                self.current_epg = None;
                self.set_toast(self.tr(T::GuideLiveToast, &[&channel.name, &entry.title]));
                self.close_guide();
            }
            Playable::Replay => {
                tracing::info!(
                    "guide: [CATCHUP] {} | {} ({} {} -> {})",
                    channel.name,
                    entry.title,
                    entry.start.with_timezone(&chrono::Local).format("%Y-%m-%d"),
                    from,
                    to
                );
                let minutes = (entry.end - entry.start).num_minutes().max(1) as u32;
                let url = self
                    .catalog
                    .portal()
```

```rust
        let name = crate::guide::cache::file_name(&creds.host, creds.port);
        Some(self.storage.cache_dir().join(name))
    }

    /// What the cache file gets: the guide's channels that have EPG; adult ones
    /// never.
    fn epg_cache_contents(
        &self,
    ) -> Option<(std::path::PathBuf, Vec<crate::guide::cache::ToSave>)> {
        let path = self.epg_cache_path()?;
        let channels = self
            .guide_channels
            .iter()
            .filter(|c| !c.adult)
            .filter_map(|c| {
                Some(crate::guide::cache::ToSave {
                    id: c.archive_id,
                    epg: self.epg_store.get(c.archive_id)?.clone(),
                    archive_days: c.archive_days,
                })
            })
            .collect();
        Some((path, channels))
    }

    /// Reads the cache file once per catalog, on a thread of its own, as soon
    /// as the catalog has loaded, and takes in what it held.
    fn read_epg_cache(&mut self) {
        if self.epg_cache_read_for != Some(self.catalog_generation) && self.catalog.is_loaded() {
            self.epg_cache_read_for = Some(self.catalog_generation);
            if let Some(path) = self.epg_cache_path() {
                let (slot, generation) = (self.epg_cache_slot.clone(), self.catalog_generation);
                std::thread::spawn(move || {
                    let read = crate::guide::cache::load(&path);
                    *slot.lock() = Some((generation, read));
                });
            }
        }
        let Some((generation, read)) = self.epg_cache_slot.lock().take() else {
            return;
        };
        if generation != self.catalog_generation {
            return;
        }
        match read {
            Ok(channels) => {
                let known: HashSet<i64> =
                    self.guide_channels.iter().map(|c| c.archive_id).collect();
                let mut kept = 0;
                for (id, epg) in channels {
                    if known.contains(&id) {
                        self.epg_store.insert(id, epg);
                        kept += 1;
                    }
                }
                tracing::info!(
                    "guide: epg cache read ({} channels, {} programmes)",
                    kept,
                    self.epg_store.programmes()
                );
            }
            Err(e) => tracing::warn!("guide: epg cache unreadable ({}) - building a new one", e),
        }
    }

    /// Writes the cache file, on a thread of its own, once the EPG that came in
    /// is complete (nothing in flight, no guide channel left to fetch), or once
    /// it has been coming in for a minute (a long first round, channels that
    /// keep failing). Not at a pause of the fetching: a stream that starts
    /// stops it for a while, and a file written then would hold a few channels.
    fn write_epg_cache_when_due(&mut self) {
        let Some(since) = self.epg_cache_dirty_since else {
            return;
        };
        let now = chrono::Utc::now();
        let complete = self.epg_fetcher.in_flight().is_empty()
            && !self
                .guide_channels
                .iter()
                .any(|c| self.epg_store.needs_fetch(c.archive_id, now));
        if !complete && since.elapsed() < Duration::from_secs(60) {
            return;
        }
        if let Some((path, channels)) = self.epg_cache_contents() {
            self.epg_cache_dirty_since = None;
            std::thread::spawn(move || write_epg_cache(&path, &channels));
        }
    }
```
