# M3U sources next to Xtream (round 1) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bongo Player plays M3U lists (such as iptv-org's 11,262 free channels) as a second kind of source next to an Xtream portal: one source at a time, chosen in the settings (`o` → Bronnen), channels only in this round.

**Architecture:** A pure reader (`m3u.rs`) turns a list into catalog entries with stable stream ids (SHA-256 of a per-channel key) and stream URLs that carry their own headers, Kodi-style (`url|User-Agent=…`). `portal/m3u.rs` is a second `Portal`: it shows the saved list (`config\cache\m3u-<id>.m3u`) at once and fetches the fresh one in the background, and plays straight from the channels' servers, not through the relay. `sources.rs` keeps every source in `BongoPlayer.ini` (the 0.6.1 line `portal=` stays) and `storage.rs` keeps favorites, presets and the last channel per source. The player hands a load's headers to mpv as options of that one file. The settings' Portal pane becomes Bronnen: add, change, delete, and use a source.

**Tech Stack:** Rust 2021, egui/eframe 0.27.2, tokio, reqwest 0.12 (rustls), ring 0.17 (SHA-256), urlencoding 2, libmpv (client API 2.5, git build 2026-05-22), wiremock 0.6 and tempfile 3 (tests), Python 3 (`mock_portal.py`), PowerShell 5.1 (e2e).

**Spec:** `docs/superpowers/specs/2026-10-14-m3u-bronnen-design.md`

## Rulings

The spec is the authority. These rulings settle what it leaves open, or where a literal reading would hurt. Task 11 writes them into the spec as its section 10.

1. **`o` cannot open the settings from the setup prompt.** Scenario T12-5 requires that typing there never fires a hotkey. The prompt's new line is therefore a link that opens the settings on Bronnen, with a new M3U source in the form. The link is the prompt's last Tab stop. Enter on the link does not also submit the form. While the settings are open, the prompt's form is not drawn.
2. **The ini format.**
   - `portal=<address>` comes first. It is a copy of the first Xtream source's address, for 0.6.1.
   - Every source has a line `source=<id>;<kind>;<name>;<address>`, with kind `xtream` or `m3u`.
   - `active=<id>` names the source in use.
   - One Xtream source with id 1, no name of its own and active is written as the `portal=` line alone. That is 0.6.1's ini, so a fresh setup and the e2e checks that compare the whole ini still see one line.
   - With `source=` lines present, `portal=` is only a copy and is not read.
   - A name loses `;`, CR and LF. Ids are numbers: 1 plus the highest id in use.
   - With no Xtream source, 0.6.1 may take an M3U line that holds an `@` for credentials and fail to connect. That is accepted: a downgrade cannot play M3U anyway.
3. **Names.**
   - An empty stored name means the default of its kind: "Portaal"/"Portal"/"Portal", or "M3U-lijst"/"M3U list"/"M3U-Liste".
   - A name saved equal to its kind's default in the current language is stored empty.
   - An empty field cannot be saved. This follows the spec.
4. **Data per source.**
   - Source 1 keeps 0.6.1's files: `favorites.json`, `presets.json` and `last_watched.json`.
   - Other sources use `favorites-<id>.json` and so on, and `cache\m3u-<id>.m3u`.
   - The portal of `--xtream` (with real values) uses source 1's files, as 0.6.1 did.
   - The files of the source whose data is in use are never deleted.
   - A source added while the `--xtream` portal runs, with no source saved yet, takes id 1, whose files that portal uses too. That is accepted: only the e2e runs and developers start with `--xtream` and real values. The scenarios that add a source therefore start from a saved portal.
5. **Switching.**
   - Using another source works as a start on it: what plays stops, and that source's last channel resumes.
   - Saving the source in use applies at once. For Xtream that happens after the connection test, and Save on the `--xtream` row still keeps and uses the credentials, as in 0.6.1. For M3U the list is read again, and a changed address drops the old saved list.
   - A new source comes into use only when nothing usable is in use. Otherwise it is added, and "Actief maken" switches to it.
6. **Deleting.** The source in use cannot be deleted: its Delete button is disabled. Delete asks for a second press ("Echt verwijderen?"), because it takes the favorites with it.
7. **Headers per load.**
   - They ride in the stream URL, Kodi-style: `url|User-Agent=…&Referer=…`, with the values percent-encoded. So `last_watched.json`, reloads and favorites keep them without new fields.
   - The player turns them into mpv options for that one file: `loadfile <url> replace -1 user-agent=%<n>%<value>,referrer=%<n>%<value>`. The `-1` is the index argument that mpv 0.38 added before the options. `%<n>%` quotes a value of `n` bytes, whatever commas or colons it holds.
   - A list line that ends in Kodi's own `|User-Agent=…` is read the same way and wins over `#EXTVLCOPT`.
   - `#EXTVLCOPT` headers wait for the next URL line, also across an `#EXTINF`. `http-referer` and `http-referrer` both count.
8. **Reading a list.**
   - A line is a URL only when it holds `://`.
   - The name follows the first comma outside quotes, not the last. That deviates from spec §3.4: a name may hold commas, and the attributes before it are quoted. The name falls back to `tvg-name`, then to the URL.
   - Not a list: the first non-blank character is `<` (an HTML page), or no channel came out.
9. **Changed or not.**
   - A download is "the same" when its bytes equal the saved file. The shown catalog then stays, with no revision bump. Internally that is `PortalError::Unchanged`.
   - The list download uses the portal's User-Agent (`BongoPlayer/<version>`) and a 30 s time-out (2.55 MB on a slow line).
   - Download errors drop their URL (`reqwest::Error::without_url`).
10. **Stream errors name the channel**, Xtream too: "streamfout op {0} - …" when the name is known. The 407 fallback stays Xtream's alone.
11. **What an M3U source does not have.**
    - It has no quality ladder: `+`/`-` say there is no other quality.
    - A zap makes no EPG request.
    - It is never adult: the catalog says "not adult" before the list has loaded, so a resume never waits for it.
    - `g` gives a toast and opens no guide.
12. **The command line's portal** (`--xtream` with real values) is a row of its own in Bronnen ("--xtream (opdrachtregel)"), and no saved row is marked active then. Save on it keeps it as the first saved Xtream source, updating that one or adding one when there is none, and uses it.
13. **Logging.**
    - An M3U source is logged as `source: m3u <id> (<host>)`, with "file" in place of a host for a file.
    - An Xtream source keeps 0.6.1's line `portal: xtream <user>@host:port`.
    - `redact()` also masks `user:pass@` in any URL, and the query of `.m3u`, `.m3u8` and `get.php` URLs, as `?<q>`.
14. **The commit scan** (`check-staged.sh`) checks every Xtream user and password in the ini. Of every M3U address it checks the secrets: the `user:pass@` part and the values of `username`, `user`, `password`, `pass` and `token`. A public M3U address is no secret: the spec itself quotes iptv-org's. Values under 3 characters are skipped.
15. **Bronnen keeps the Portal row's place** (second in the list). `o;DOWN;ENTER` lands on the Server field of the source in use: the Name field sits above it, but the first focus goes past it. So the e2e Tab counts to Test and Save stay as they are.
16. **The PIN reset** checks the password of the Xtream portal in use, else that of the first saved Xtream source.
17. **The version is not bumped here.** The user decides at release.

## Review Focus

These are the five inputs the spec implies but no test of the plain feature exercises, most likely to bite first. Each has its test in the owning task.

1. **The provider reorders the list, or moves a channel to another server.** Favorites and presets still point at the same channel: ids come from keys, not from places or URLs. → Task 1, `the_stream_id_follows_the_key_not_the_place_or_the_address`.
2. **The download is an HTML error page with HTTP 200** (a captive portal, or a provider that is down). It is no list: the saved list stays, and the user is told "dit is geen zenderlijst". → Task 5, `an_html_page_with_200_keeps_the_saved_list_and_says_so`.
3. **The M3U address holds a password or a token** (a paid provider). It never reaches the log: not in the start line, not in a failed download, not in mpv's loadfile line. → Task 2, `an_m3u_address_with_a_password_or_token_is_masked`; Task 4, `a_failed_download_names_no_address`.
4. **Up or Down right after a resume, before the list has loaded.** Zapping continues from the resumed channel, not from the end of the list. → Task 7, `up_after_a_resume_continues_from_the_resumed_m3u_channel`.
5. **Switching sources while the other source's stream plays, then the next start.** The old stream stops, the new source's last channel resumes, and the next start opens that source. → Task 8, `switching_stops_the_old_stream_and_resumes_the_new_sources_last_channel` and `the_next_start_opens_the_source_that_was_in_use`.

### Task 1: The M3U reader

A pure module that turns a list into catalog entries. Each channel gets a key and, from that key, a stream id that stays the same when the provider reorders the list or moves a stream. Each stream URL carries the headers it needs.

**Files:**
- Create: `rust/src/m3u.rs`
- Modify: `rust/src/lib.rs` (`pub mod m3u;` after `pub mod legacy;`)
- Test: `rust/tests/test_m3u.rs` (new)

**Interfaces:**
- Consumes: `crate::portal::LiveChannel` (fields `stream_id, name, category_id, epg_channel_id, tv_archive, tv_archive_duration, is_adult, stream_icon`).
- Produces:
  ```rust

  pub struct M3uList { pub channels: Vec<M3uChannel>, pub epg_url: Option<String> }
  ```

- [ ] **Step 1: Write the failing tests**

Create `rust/tests/test_m3u.rs`:

```rust
use bongo_player::m3u::{
    keys, parse, read, split_headers, stream_id, with_headers, xtream_link, Headers, M3uChannel,
};

/// A list in iptv-org's form, without real addresses.
const LIST: &str = "#EXTM3U x-tvg-url=\"https://epg.example/guide.xml.gz\"\n\
#EXTINF:-1 tvg-id=\"Een.nl@SD\" tvg-logo=\"https://logos.example/een.png\" group-title=\"General;News\",Kanaal Een (1080p)\n\
https://a.example/een/index.m3u8\n\
#EXTINF:-1 tvg-id=\"\" group-title=\"Kids\",Kanaal Twee\n\
#EXTVLCOPT:http-user-agent=Mozilla/5.0 (Windows NT 10.0; Win64; x64)\n\
#EXTVLCOPT:http-referrer=https://www.example.com/\n\
http://b.example/twee.m3u8\n";

fn one(text: &str) -> M3uChannel {
    let list = parse(text);
    assert_eq!(list.channels.len(), 1, "{text:?}");
    list.channels.into_iter().next().unwrap()
}

#[test]
fn reads_the_attributes_the_name_and_the_url() {
    let list = parse(LIST);
    assert_eq!(list.channels.len(), 2);
    let een = &list.channels[0];
    assert_eq!(een.name, "Kanaal Een (1080p)");
    assert_eq!(een.url, "https://a.example/een/index.m3u8");
    assert_eq!(een.tvg_id.as_deref(), Some("Een.nl@SD"));
    assert_eq!(een.logo.as_deref(), Some("https://logos.example/een.png"));
    assert_eq!(een.group.as_deref(), Some("General;News"), "several groups in one field");
    assert_eq!((een.user_agent.as_deref(), een.referrer.as_deref()), (None, None));
    let twee = &list.channels[1];
    assert_eq!(twee.tvg_id, None, "an empty tvg-id is none");
    assert_eq!(twee.group.as_deref(), Some("Kids"));
}

#[test]
fn a_name_may_hold_commas_and_a_quoted_value_too() {
    let c = one("#EXTINF:-1 group-title=\"News, World\",Hello, World\nhttp://a.example/1\n");
    assert_eq!(c.group.as_deref(), Some("News, World"));
    assert_eq!(c.name, "Hello, World");
}

#[test]
fn extvlcopt_headers_go_to_the_next_url() {
    let twee = &parse(LIST).channels[1];
    assert_eq!(
        twee.user_agent.as_deref(),
        Some("Mozilla/5.0 (Windows NT 10.0; Win64; x64)")
    );
    assert_eq!(twee.referrer.as_deref(), Some("https://www.example.com/"));
    // Before the #EXTINF, and spelled the HTTP way: they still wait for the URL.
    let c = one("#EXTVLCOPT:http-referer=https://r.example/\n#EXTINF:-1,Een\nhttp://a.example/1\n");
    assert_eq!(c.referrer.as_deref(), Some("https://r.example/"));
    // Used once: the channel after it has none.
    let list = parse("#EXTVLCOPT:http-user-agent=UA\nhttp://a.example/1\nhttp://a.example/2\n");
    assert_eq!(list.channels[0].user_agent.as_deref(), Some("UA"));
    assert_eq!(list.channels[1].user_agent, None);
}

#[test]
fn a_kodi_header_suffix_is_read_and_wins_over_extvlcopt() {
    let c = one("#EXTINF:-1,Een\n#EXTVLCOPT:http-user-agent=Vlc\nhttp://a.example/1.m3u8|User-Agent=Kodi%2F21&Referer=https%3A%2F%2Fk.example%2F\n");
    assert_eq!(c.url, "http://a.example/1.m3u8");
    assert_eq!(c.user_agent.as_deref(), Some("Kodi/21"));
    assert_eq!(c.referrer.as_deref(), Some("https://k.example/"));
}

#[test]
fn a_bom_crlf_and_no_header_are_fine() {

}

fn channel(name: &str, tvg_id: Option<&str>) -> M3uChannel {
    M3uChannel {
        name: name.into(),
        url: format!("http://a.example/{name}"),
        tvg_id: tvg_id.map(str::to_owned),
        ..M3uChannel::default()
    }
}
```

```rust
//! Reading an M3U list: its channels, a stable key and stream id for each,
//! and the headers a stream wants, carried in its URL. Pure: no I/O.
//!
//! Tolerant of what lists in the wild do: a BOM, CRLF line ends, no `#EXTM3U`
//! header, an `#EXTINF` with no URL after it (dropped), a URL with no `#EXTINF`
//! (named after its URL), and `#` lines it does not know (skipped).

use crate::portal::LiveChannel;
use std::collections::{HashMap, HashSet};

/// One channel of a list, as the file has it.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct M3uChannel {
    /// The name after the `#EXTINF`'s comma, else `tvg-name`, else the URL.
    pub name: String,
    /// The stream's address, without the headers that came with it.
    pub url: String,
    pub tvg_id: Option<String>,
    pub logo: Option<String>,
    /// `group-title`: one group, or several separated by `;`.
    pub group: Option<String>,
    pub user_agent: Option<String>,
    pub referrer: Option<String>,
}

/// A list as the file has it.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct M3uList {
    pub channels: Vec<M3uChannel>,
    /// The header's `x-tvg-url` (or `url-tvg`): the list's XMLTV guide, kept
    /// for round 2.
    pub epg_url: Option<String>,
}

/// What a stream needs sent with it.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct Headers {
    pub user_agent: Option<String>,
    pub referrer: Option<String>,
}

/// What a channel's stream id plays.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Stream {
    /// The address with its headers (see [`with_headers`]).
    pub url: String,
    /// `tvg-logo`, kept for round 2.
    pub logo: Option<String>,
}

/// A list read for the app (see [`read`]).
#[derive(Debug, Clone, Default)]
pub struct Playlist {
    /// The channels for the catalog, in file order.
    pub live: Vec<LiveChannel>,
    /// What each stream id plays.
    pub streams: HashMap<i64, Stream>,
    /// See [`M3uList::epg_url`].
    pub epg_url: Option<String>,
}

impl Playlist {
    /// About how many bytes the list keeps on the heap: what its strings hold,
    /// and the vector and the map around them. For the memory budget.
    pub fn heap_bytes(&self) -> usize {
        let opt = |s: &Option<String>| s.as_ref().map_or(0, String::capacity);
        let live: usize = self
            .live
            .iter()
            .map(|c| {
                c.name.capacity() + opt(&c.category_id) + opt(&c.epg_channel_id) + opt(&c.stream_icon)
            })
            .sum();
        let streams: usize = self
            .streams
            .values()
            .map(|s| s.url.capacity() + opt(&s.logo))
            .sum();
        live + self.live.capacity() * std::mem::size_of::<LiveChannel>()
            + streams
            + self.streams.capacity() * (std::mem::size_of::<(i64, Stream)>() + 1)
            + opt(&self.epg_url)
    }
}

/// What an `#EXTINF` line says about the channel whose URL follows it.
#[derive(Debug, Default)]
struct Info {
    name: String,
    tvg_id: Option<String>,
    tvg_name: Option<String>,
    logo: Option<String>,
    group: Option<String>,
}

impl Info {
    /// `rest` is what follows `#EXTINF:`: the duration and the attributes, a
    /// comma, the name. The first comma outside quotes ends the attributes, so
    /// a name may hold commas of its own.
    fn of(rest: &str) -> Self {
        let mut in_quotes = false;
        let mut comma = None;
        for (i, c) in rest.char_indices() {
            match c {
                '"' => in_quotes = !in_quotes,
                ',' if !in_quotes => {
                    comma = Some(i);
                    break;
                }
                _ => {}
            }
        }
        let (head, name) = match comma {
            Some(i) => (&rest[..i], rest[i + 1..].trim()),
            None => (rest, ""),
        };
        let pairs = pairs(head);
        Info {
            name: name.to_owned(),
            tvg_id: value_of(&pairs, "tvg-id"),
            tvg_name: value_of(&pairs, "tvg-name"),
            logo: value_of(&pairs, "tvg-logo"),
            group: value_of(&pairs, "group-title"),
        }
    }
}

/// Reads a list (see the module's doc). A line is a stream only when it holds
/// `://`; `#EXTVLCOPT` headers wait for the next one.
pub fn parse(text: &str) -> M3uList {
    let text = text.strip_prefix('\u{feff}').unwrap_or(text);
    let mut list = M3uList::default();
    let mut info: Option<Info> = None;
    let mut pending = Headers::default();
    for line in text.lines() {
        let line = line.trim();
        if line.is_empty() {
            continue;
        }
        if let Some(rest) = strip_prefix_ci(line, "#EXTM3U") {
            let pairs = pairs(rest);
            list.epg_url = value_of(&pairs, "x-tvg-url").or_else(|| value_of(&pairs, "url-tvg"));
        } else if let Some(rest) = strip_prefix_ci(line, "#EXTINF:") {
            info = Some(Info::of(rest));
        } else if let Some(rest) = strip_prefix_ci(line, "#EXTVLCOPT:") {
            if let Some((key, value)) = rest.split_once('=') {
                let value = Some(value.trim().to_owned()).filter(|v| !v.is_empty());
                match key.trim().to_ascii_lowercase().as_str() {
                    "http-user-agent" => pending.user_agent = value,
                    "http-referrer" | "http-referer" => pending.referrer = value,
                    _ => {}
                }
            }
        } else if !line.starts_with('#') && line.contains("://") {
            let (url, piped) = split_headers(line);
            let info = info.take().unwrap_or_default();
            let headers = std::mem::take(&mut pending);
            let name = [info.name, info.tvg_name.unwrap_or_default()]
                .into_iter()
                .find(|n| !n.is_empty())
                .unwrap_or_else(|| url.to_owned());
            list.channels.push(M3uChannel {
                name,
                url: url.to_owned(),
                tvg_id: info.tvg_id,
                logo: info.logo,
                group: info.group,
                user_agent: piped.user_agent.or(headers.user_agent),
                referrer: piped.referrer.or(headers.referrer),
            });
        }
    }
    list
}

/// The `key="value"` (or `key=value`) pairs in `text`, keys in lower case.
fn pairs(text: &str) -> Vec<(String, String)> {
    let mut found = Vec::new();
    let mut rest = text;
    while let Some(eq) = rest.find('=') {
        let key = rest[..eq].rsplit(char::is_whitespace).next().unwrap_or("").trim();
        let after = &rest[eq + 1..];
        let (value, next) = match after.strip_prefix('"') {
            Some(quoted) => match quoted.find('"') {
                Some(end) => (&quoted[..end], &quoted[end + 1..]),
                None => (quoted, ""),
            },
            None => {
                let end = after.find(char::is_whitespace).unwrap_or(after.len());
                (&after[..end], &after[end..])
            }
        };
        if !key.is_empty() {
            found.push((key.to_ascii_lowercase(), value.to_owned()));
        }
        rest = next;
    }
    found
}

/// The value of `key` among `pairs`, unless it is blank.
fn value_of(pairs: &[(String, String)], key: &str) -> Option<String> {
    pairs
        .iter()
        .find(|(k, _)| k == key)
        .map(|(_, v)| v.trim().to_owned())
        .filter(|v| !v.is_empty())
}

/// `line` after `prefix`, when it starts with it in any case.
fn strip_prefix_ci<'a>(line: &'a str, prefix: &str) -> Option<&'a str> {
    let head = line.get(..prefix.len())?;
    head.eq_ignore_ascii_case(prefix)
        .then(|| &line[prefix.len()..])
}

/// Each channel's key, in the order of `channels`: its `tvg-id` when no other
/// channel of the list has that one, else its name. A key that came before
/// gets "#2", "#3", … in file order, skipping keys that are taken already.
pub fn keys(channels: &[M3uChannel]) -> Vec<String> {
    let mut tvg_ids: HashMap<&str, usize> = HashMap::new();
    for c in channels {
        if let Some(id) = c.tvg_id.as_deref().map(str::trim).filter(|id| !id.is_empty()) {
            *tvg_ids.entry(id).or_default() += 1;
        }
    }
    let mut taken: HashSet<String> = HashSet::with_capacity(channels.len());
    let mut next: HashMap<String, usize> = HashMap::new();
    channels
        .iter()
        .map(|c| {
            let base = match c.tvg_id.as_deref().map(str::trim) {
                Some(id) if tvg_ids.get(id) == Some(&1) => id.to_owned(),
                _ => c.name.trim().to_owned(),
            };
            let mut n = next.get(&base).copied().unwrap_or(1);
            let mut key = if n == 1 {
                base.clone()
            } else {
                format!("{base}#{n}")
            };
            while taken.contains(&key) {
                n += 1;
                key = format!("{base}#{n}");
            }
            next.insert(base, n + 1);
            taken.insert(key.clone());
            key
        })
        .collect()
}

/// The stream id of a channel key: the first 8 bytes of its SHA-256 as a
/// number, the top bit cleared so it is never negative. The same on every
/// machine and every Rust version, which std's `DefaultHasher` does not promise.
pub fn stream_id(key: &str) -> i64 {
    let digest = ring::digest::digest(&ring::digest::SHA256, key.as_bytes());
    let mut first = [0u8; 8];
    first.copy_from_slice(&digest.as_ref()[..8]);
    (u64::from_be_bytes(first) >> 1) as i64
}

/// The list in `text` for the app: `None` when it is no channel list (an HTML
/// page, or no stream in it). The catalog's entries come in file order, with
/// their [`keys`]' stream ids; each stream carries its headers in its URL.
pub fn read(text: &str) -> Option<Playlist> {
    if text.trim_start_matches('\u{feff}').trim_start().starts_with('<') {
        return None;
    }
    let list = parse(text);
    if list.channels.is_empty() {
        return None;
    }
    let keys = keys(&list.channels);
    let mut live = Vec::with_capacity(list.channels.len());
    let mut streams = HashMap::with_capacity(list.channels.len());
    for (channel, key) in list.channels.into_iter().zip(keys) {
        let stream_id = stream_id(&key);
        let url = with_headers(
            channel.url,
            channel.user_agent.as_deref(),
            channel.referrer.as_deref(),
        );
        streams.insert(
            stream_id,
            Stream {
                url,
                logo: channel.logo,
            },
        );
        live.push(LiveChannel {
            stream_id,
            name: channel.name,
            category_id: channel.group,
            epg_channel_id: channel.tvg_id,
            tv_archive: 0,
            tv_archive_duration: 0,
            is_adult: false,
            stream_icon: None,
        });
    }
    Some(Playlist {
        live,
        streams,
        epg_url: list.epg_url,
    })
}

/// `url` with the headers its server wants, the way Kodi writes them:
/// `url|User-Agent=…&Referer=…`, the values percent-encoded. With none, `url`
/// as it is.
pub fn with_headers(url: String, user_agent: Option<&str>, referrer: Option<&str>) -> String {
    let parts: Vec<String> = [("User-Agent", user_agent), ("Referer", referrer)]
        .into_iter()
        .filter_map(|(name, value)| Some(format!("{name}={}", urlencoding::encode(value?))))
        .collect();
    if parts.is_empty() {
        url
    } else {
        format!("{url}|{}", parts.join("&"))
    }
}

/// The address and the headers of a URL that [`with_headers`] made, or that a
/// list wrote in Kodi's way. Header names count in any case, `Referrer` as
/// `Referer`; other headers are ignored.
pub fn split_headers(url: &str) -> (&str, Headers) {
    let Some((address, options)) = url.split_once('|') else {
        return (url, Headers::default());
    };
    let mut headers = Headers::default();
    for option in options.split('&') {
        let Some((name, value)) = option.split_once('=') else {
            continue;
        };
        let value = urlencoding::decode(value)
            .map(|v| v.into_owned())
            .unwrap_or_else(|_| value.to_owned());
        match name.trim().to_ascii_lowercase().as_str() {
            "user-agent" => headers.user_agent = Some(value),
            "referer" | "referrer" => headers.referrer = Some(value),
            _ => {}
        }
    }
    (address, headers)
}

/// The credentials (`user:pass@host:port`) of an Xtream portal's M3U link,
/// `…/get.php?username=…&password=…`; `None` for any other address.
pub fn xtream_link(address: &str) -> Option<String> {
    let url = reqwest::Url::parse(address.trim()).ok()?;
    let is_get_php = url.path().to_ascii_lowercase().ends_with("/get.php");
    if !matches!(url.scheme(), "http" | "https") || !is_get_php {
        return None;
    }
    let (mut user, mut pass) = (None, None);
    for (key, value) in url.query_pairs() {
        match key.as_ref() {
            "username" => user = Some(value.into_owned()),
            "password" => pass = Some(value.into_owned()),
            _ => {}
        }
    }
    let user = user.filter(|u| !u.is_empty())?;
    let pass = pass.filter(|p| !p.is_empty())?;
    let port = url.port_or_known_default().unwrap_or(80);
    Some(format!("{user}:{pass}@{}:{port}", url.host_str()?))
}
```

```rust
//! Credentials never reach the log: portal URLs carry them in the path
//! (`/live/<user>/<pass>/…`) or in the query (`username=…&password=…`); an M3U
//! list's address may hold them as `user:pass@` or as a token in its query.

use std::borrow::Cow;

const PATH_KINDS: [&str; 4] = ["/live/", "/movie/", "/series/", "/timeshift/"];

/// `text` with every portal user name and password replaced by `<u>` / `<p>`,
/// the `user:pass@` of any URL by `<u>:<p>@`, and the query of a list's
/// address (`.m3u`, `.m3u8`, `get.php`) by `<q>`. Borrows when there is
/// nothing to hide, the common case for log lines.
pub fn redact(text: &str) -> Cow<'_, str> {
    let has_path = PATH_KINDS.iter().any(|k| text.contains(k));
    let has_query = text.contains("username=") || text.contains("password=");
    let has_userinfo = text.contains("://") && text.contains('@');
    let has_list = text.contains(".m3u") || text.contains("get.php");
    if !has_path && !has_query && !has_userinfo && !has_list {
        return Cow::Borrowed(text);
    }
    let mut out = text.to_string();
    for kind in PATH_KINDS {
        out = redact_path(&out, kind);
    }
    out = redact_query(&out, "username=", "<u>");
    out = redact_query(&out, "password=", "<p>");
    out = redact_userinfo(&out);
    out = redact_list_query(&out);
    if out == text {
        Cow::Borrowed(text)
    } else {
        Cow::Owned(out)
    }
}

/// The host of a web address, for a log line that must not hold the address
/// itself; "file" for anything that is no URL.
pub fn url_host(address: &str) -> String {
    reqwest::Url::parse(address.trim())
        .ok()
        .and_then(|u| u.host_str().map(str::to_owned))
        .unwrap_or_else(|| "file".to_owned())
}

/// `scheme://user:pass@host` → `scheme://<u>:<p>@host` (`<u>@` without a
/// password), for every URL in `s`.
fn redact_userinfo(s: &str) -> String {
    let mut out = String::with_capacity(s.len());
    let mut rest = s;
    while let Some(i) = rest.find("://") {
        let after = i + 3;
        out.push_str(&rest[..after]);
        let tail = &rest[after..];
        let end = tail
            .find(|c: char| matches!(c, '/' | '?' | '#' | '"' | '\'') || c.is_whitespace())
            .unwrap_or(tail.len());
        let authority = &tail[..end];
        match authority.rfind('@') {
            Some(at) => {
                out.push_str(if authority[..at].contains(':') {
                    "<u>:<p>"
                } else {
                    "<u>"
                });
                out.push_str(&authority[at..]);
            }
            None => out.push_str(authority),
        }
        rest = &tail[end..];
    }
    out.push_str(rest);
    out
}

/// The query of a list's address (`….m3u?…`, `….m3u8?…`, `…/get.php?…`) →
/// `?<q>`: a provider's token lives there as often as a password.
fn redact_list_query(s: &str) -> String {
    let mut out = String::with_capacity(s.len());
    let mut rest = s;
    while let Some(q) = rest.find('?') {
        let before = &rest[..q];
        let start = before
            .rfind(|c: char| c.is_whitespace() || matches!(c, '"' | '\'' | '('))
            .map_or(0, |i| i + 1);
        let path = before[start..].to_ascii_lowercase();
        let tail = &rest[q + 1..];
        let end = tail
            .find(|c: char| c.is_whitespace() || matches!(c, '"' | '\'' | ')'))
            .unwrap_or(tail.len());
        out.push_str(before);
        if path.ends_with(".m3u") || path.ends_with(".m3u8") || path.ends_with("get.php") {
            out.push_str("?<q>");
        } else {
            out.push('?');
            out.push_str(&tail[..end]);
        }
        rest = &tail[end..];
    }
    out.push_str(rest);
    out
}
```

```rust
//! in use. One Xtream source alone, with id 1, no name of its own and in use,
//! is written as the `portal=` line only: 0.6.1's ini, word for word.

use crate::i18n::{t, Lang, T};
use std::path::Path;

/// A source's short, fixed number: its data files carry it, never its address.
pub type SourceId = u32;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SourceKind {
    Xtream,
    M3u,
}

impl SourceKind {
    /// The ini's word for it.
    pub fn code(self) -> &'static str {
        match self {
            SourceKind::Xtream => "xtream",
            SourceKind::M3u => "m3u",
        }
    }

    pub fn from_code(code: &str) -> Option<Self> {
        match code.trim().to_ascii_lowercase().as_str() {
            "xtream" => Some(SourceKind::Xtream),
            "m3u" => Some(SourceKind::M3u),
            _ => None,
        }
    }

    /// The name a source of this kind has when the user gave it none.
    pub fn default_name(self, lang: Lang) -> &'static str {
        t(
            lang,
            match self {
                SourceKind::Xtream => T::DefaultPortalName,
                SourceKind::M3u => T::DefaultListName,
            },
        )
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Source {
    pub id: SourceId,
    pub kind: SourceKind,
    /// The user's name for it; empty: the default name of its kind.
    pub name: String,
    /// `user:pass@host:port` for Xtream; an http(s) URL or a file for M3U.
    pub address: String,
}

impl Source {
    pub fn display_name(&self, lang: Lang) -> String {
        if self.name.is_empty() {
            self.kind.default_name(lang).to_owned()
        } else {
            self.name.clone()
        }
    }
}

/// Which source the settings' form shows, and so which one its Save is for.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Editing {
    /// A saved source.
    Saved(SourceId),
    /// The portal of `--xtream`, which is not saved; saved, it becomes the
    /// first Xtream source.
    CommandLine,
    /// One that is being added.
    New,
}

/// What a Save in the settings' sources section hands the app.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct SourceDraft {
    pub editing: Editing,
    pub kind: SourceKind,
    pub name: String,
    /// The credentials line (`user:pass@host:port`) of an Xtream source, the
    /// URL or file of an M3U one.
    pub address: String,
}

/// Every saved source, in the order they were added, and the one in use.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct Sources {
    list: Vec<Source>,
    active: Option<SourceId>,
}

impl Sources {
    pub const EMPTY: Sources = Sources {
        list: Vec::new(),
        active: None,
    };

    /// The sources in an ini's text. Lines that make no source are skipped; so
    /// are `#` and `;` comments and a BOM. Without `source=` lines the first
    /// line with credentials (0.6.1's rule: `key=value` when the key holds no
    /// `@` or `:`, else the whole line) is source 1, Xtream, in use. An
    /// `active=` that names no source falls back to the first.
    pub fn parse(text: &str) -> Self {
        let text = text.strip_prefix('\u{feff}').unwrap_or(text);
        let mut list: Vec<Source> = Vec::new();
        let mut active = None;
        let mut portal = None;
        for line in text.lines() {
            let line = line.trim();
            if line.is_empty() || line.starts_with('#') || line.starts_with(';') {
                continue;
            }
            if let Some(rest) = line.strip_prefix("source=") {
                if let Some(source) = source_line(rest) {
                    if !list.iter().any(|s| s.id == source.id) {
                        list.push(source);
                    }
                }
            } else if let Some(rest) = line.strip_prefix("active=") {
                active = rest.trim().parse().ok();
            } else if portal.is_none() {
                let value = match line.split_once('=') {
                    Some((key, value)) if !key.contains(['@', ':']) => value.trim(),
                    _ => line,
                };
                if value.contains('@') {
                    portal = Some(value.to_owned());
                }
            }
        }
        if list.is_empty() {
            if let Some(address) = portal {
                list.push(Source {
                    id: 1,
                    kind: SourceKind::Xtream,
                    name: String::new(),
                    address,
                });
                active = Some(1);
            }
        }
        let active = active
            .filter(|id| list.iter().any(|s| s.id == *id))
            .or_else(|| list.first().map(|s| s.id));
        Sources { list, active }
    }

    /// The ini's text for these sources (see the module's doc).
    pub fn to_text(&self) -> String {
        let mut text = String::new();
        if let Some(portal) = self.first_xtream() {
            text.push_str(&format!("portal={}\n", portal.address));
        }
        let only_the_portal = matches!(
            self.list.as_slice(),
            [s] if s.id == 1 && s.kind == SourceKind::Xtream && s.name.is_empty()
        ) && self.active == Some(1);
        if only_the_portal {
            return text;
        }
        for s in &self.list {
            text.push_str(&format!(
                "source={};{};{};{}\n",
                s.id,
                s.kind.code(),
                s.name,
                s.address
            ));
        }
        if let Some(id) = self.active {
            text.push_str(&format!("active={id}\n"));
        }
        text
    }

    /// The sources in the ini at `path`; none when it is missing or unreadable.
    pub fn load(path: &Path) -> Self {
        std::fs::read_to_string(path)
            .map(|text| Self::parse(&text))
            .unwrap_or_default()
    }

    /// Writes the ini through a temp file beside `path`, renamed over it: a
    /// failed write leaves the old ini as it was, and no temp file with
    /// passwords in it.
    pub fn save(&self, path: &Path) -> std::io::Result<()> {
        let tmp = path.with_extension("ini.tmp");
        let saved = std::fs::write(&tmp, self.to_text()).and_then(|()| std::fs::rename(&tmp, path));
        if saved.is_err() {
            let _ = std::fs::remove_file(&tmp);
        }
        saved
    }

    pub fn list(&self) -> &[Source] {
        &self.list
    }

    pub fn get(&self, id: SourceId) -> Option<&Source> {
        self.list.iter().find(|s| s.id == id)
    }

    pub fn active_id(&self) -> Option<SourceId> {
        self.active
    }

    pub fn active(&self) -> Option<&Source> {
        self.get(self.active?)
    }

    pub fn first_xtream(&self) -> Option<&Source> {
        self.list.iter().find(|s| s.kind == SourceKind::Xtream)
    }

    /// Puts source `id` in use; false when there is no such source.
    pub fn set_active(&mut self, id: SourceId) -> bool {
        let known = self.get(id).is_some();
        if known {
            self.active = Some(id);
        }
        known
    }

    /// Keeps a source as `editing` says, and returns its id. A saved one
    /// changes its name and address, and keeps its kind. The command line's
    /// portal goes into the first Xtream source. A new one, or a command-line
    /// portal with no Xtream source to go into, is added with the next id
    /// (1 + the highest). Names lose `;`, CR and LF; both lose the spaces
    /// around them.
    pub fn keep(&mut self, editing: Editing, kind: SourceKind, name: &str, address: &str) -> SourceId {
        let target = match editing {
            Editing::Saved(id) => self.list.iter().position(|s| s.id == id),
            Editing::CommandLine => self.list.iter().position(|s| s.kind == SourceKind::Xtream),
            Editing::New => None,
        };
        let name = clean(name).replace(';', ",");
        let address = clean(address);
        match target {
            Some(i) => {
                let source = &mut self.list[i];
                source.name = name;
                source.address = address;
                source.id
            }
            None => {
                let id = self.list.iter().map(|s| s.id).max().unwrap_or(0) + 1;
                self.list.push(Source {
                    id,
                    kind,
                    name,
                    address,
                });
                id
            }
        }
    }

    /// Takes source `id` out; if it was in use, none is.
    pub fn remove(&mut self, id: SourceId) -> Option<Source> {
        let i = self.list.iter().position(|s| s.id == id)?;
        if self.active == Some(id) {
            self.active = None;
        }
        Some(self.list.remove(i))
    }
}

/// `source=` without its key: `<id>;<kind>;<name>;<address>`. `None` for an
/// id that is no number above 0, an unknown kind, or no address.
fn source_line(rest: &str) -> Option<Source> {
    let mut fields = rest.splitn(4, ';');
    let id: SourceId = fields.next()?.trim().parse().ok().filter(|id| *id > 0)?;
    let kind = SourceKind::from_code(fields.next()?)?;
    let name = fields.next()?.trim().to_owned();
    let address = fields.next()?.trim().to_owned();
    (!address.is_empty()).then_some(Source {
        id,
        kind,
        name,
        address,
    })
}

/// `text` without line breaks and the spaces around it.
fn clean(text: &str) -> String {
    crate::args::without_newlines(text).trim().to_owned()
}

/// Whether an M3U source's address is a web address to fetch (http or https,
/// with a host) rather than a file.
pub fn is_web_address(address: &str) -> bool {
    reqwest::Url::parse(address.trim())
        .is_ok_and(|u| matches!(u.scheme(), "http" | "https") && u.host_str().is_some())
}
```

```rust
//! An M3U list as a portal: the channels of one list, played straight from
//! their servers (the relay is the Xtream portal's). No films, series, EPG or
//! catch-up in round 1.
//!
//! A list at a URL is kept in a file once it came (`Storage::m3u_cache_path`):
//! the next start shows that saved list at once (`saved_catalog`) while the
//! fresh one downloads (`fetch_catalog`). A list in a file is read as it is.
//! Reading happens on a blocking thread: 11,000 channels must not hold up a
//! tokio worker, where the relay runs.

use super::{Catalog, Episode, Portal, PortalError};
use crate::epg::Epg;
use crate::m3u::{self, Playlist, Stream};
use crate::sources::{SourceId, SourceKind};
use parking_lot::RwLock;
use std::collections::HashMap;
use std::path::{Path, PathBuf};
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;
use std::time::{Duration, Instant};

/// How long the download of a list may take: iptv-org's is 2.55 MB.
const DOWNLOAD_TIMEOUT: Duration = Duration::from_secs(30);

/// Where a list comes from.
#[derive(Debug, Clone, PartialEq, Eq)]
enum Address {
    Url(String),
    File(PathBuf),
}

/// What the catalog's stream ids play, and what round 2 will want.
#[derive(Debug, Default)]
struct Lookup {
    streams: HashMap<i64, Stream>,
    epg_url: Option<String>,
}

pub struct M3uPortal {
    id: SourceId,
    address: Address,
    /// Where the list of a URL is kept once it came.
    cache: PathBuf,
    client: reqwest::Client,
    lookup: RwLock<Arc<Lookup>>,
    /// The saved list was read and is what shows: a download that is the same
    /// brings nothing new.
    saved_shown: AtomicBool,
}

impl M3uPortal {
    /// The portal of M3U source `id`. `address` is an http(s) URL or a file;
    /// the list of a URL is kept at `cache`.
    pub fn new(id: SourceId, address: &str, cache: PathBuf) -> Self {
        let address = if crate::sources::is_web_address(address) {
            Address::Url(address.trim().to_owned())
        } else {
            Address::File(PathBuf::from(address.trim()))
        };
        let client = reqwest::Client::builder()
            .user_agent(format!("{}/{}", crate::APP_ID, env!("CARGO_PKG_VERSION")))
            .timeout(DOWNLOAD_TIMEOUT)
            .build()
            .expect("build reqwest client");
        Self {
            id,
            address,
            cache,
            client,
            lookup: RwLock::new(Arc::new(Lookup::default())),
            saved_shown: AtomicBool::new(false),
        }
    }

    /// A portal whose list is `text`, read already, and the catalog it gives;
    /// `None` when `text` is no list. The app's tests start M3U sources so.
    pub fn from_text(text: &str) -> Option<(Self, Catalog)> {
        let portal = Self::new(0, "", PathBuf::new());
        let catalog = portal.install(m3u::read(text)?);
        Some((portal, catalog))
    }

    /// The logo (`tvg-logo`) of a stream id, kept for round 2.
    pub fn logo(&self, stream_id: i64) -> Option<String> {
        self.lookup.read().streams.get(&stream_id)?.logo.clone()
    }

    /// The list's XMLTV guide (`x-tvg-url`), kept for round 2.
    pub fn epg_url(&self) -> Option<String> {
        self.lookup.read().epg_url.clone()
    }

    /// Makes `playlist` what the stream ids play; its channels for the catalog.
    fn install(&self, playlist: Playlist) -> Catalog {
        let Playlist {
            live,
            streams,
            epg_url,
        } = playlist;
        *self.lookup.write() = Arc::new(Lookup { streams, epg_url });
        Catalog {
            live,
            ..Catalog::default()
        }
    }

    /// The list at `url`, as bytes. A refusal is its status; any other failure
    /// is reqwest's without the URL, which may hold a password.
    async fn download(&self, url: &str) -> Result<Vec<u8>, PortalError> {
        let answer = self
            .client
            .get(url)
            .send()
            .await
            .map_err(|e| PortalError::Http(e.without_url()))?;
        if !answer.status().is_success() {
            return Err(PortalError::Status(answer.status().as_u16()));
        }
        let body = answer
            .bytes()
            .await
            .map_err(|e| PortalError::Http(e.without_url()))?;
        Ok(body.to_vec())
    }
}

/// A downloaded list: `Unchanged` when it is the saved one and that one shows
/// (`check_saved`), else read and, once read, kept at `cache`. A list that
/// cannot be kept still plays; the next start then has none to show at once.
fn read_download(
    bytes: Vec<u8>,
    cache: &Path,
    check_saved: bool,
) -> Result<(Playlist, usize), PortalError> {
    if check_saved && std::fs::read(cache).is_ok_and(|saved| saved == bytes) {
        return Err(PortalError::Unchanged);
    }
    let playlist = m3u::read(&String::from_utf8_lossy(&bytes)).ok_or(PortalError::NotAList)?;
    if let Err(e) = write_atomic(cache, &bytes) {
        tracing::warn!("m3u: list not saved: {}", e);
    }
    Ok((playlist, bytes.len()))
}

/// A list in a file. The error names the file, which holds no credentials.
fn read_file(path: &Path) -> Result<(Playlist, usize), PortalError> {
    let bytes = std::fs::read(path)
        .map_err(|e| PortalError::File(format!("{}: {}", path.display(), e)))?;
    let playlist = m3u::read(&String::from_utf8_lossy(&bytes)).ok_or(PortalError::NotAList)?;
    Ok((playlist, bytes.len()))
}

/// `bytes` to `path` through a temp file beside it, so a write that fails
/// leaves the old list whole.
fn write_atomic(path: &Path, bytes: &[u8]) -> std::io::Result<()> {
    if let Some(dir) = path.parent() {
        std::fs::create_dir_all(dir)?;
    }
    let tmp = path.with_extension("m3u.tmp");
    let written = std::fs::write(&tmp, bytes).and_then(|()| std::fs::rename(&tmp, path));
    if written.is_err() {
        let _ = std::fs::remove_file(&tmp);
    }
    written
}

/// What a blocking reader that panicked or was cancelled leaves.
fn reader_lost(e: tokio::task::JoinError) -> PortalError {
    PortalError::Shape(format!("list reader: {e}"))
}

#[async_trait::async_trait]
impl Portal for M3uPortal {
    fn kind(&self) -> SourceKind {
        SourceKind::M3u
    }

    async fn saved_catalog(&self) -> Option<Catalog> {
        if !matches!(self.address, Address::Url(_)) {
            return None;
        }
        let t0 = Instant::now();
        let path = self.cache.clone();
        let (playlist, size) = tokio::task::spawn_blocking(move || {
            let bytes = std::fs::read(path).ok()?;
            let playlist = m3u::read(&String::from_utf8_lossy(&bytes))?;
            Some((playlist, bytes.len()))
        })
        .await
        .ok()??;
        let channels = playlist.live.len();
        let catalog = self.install(playlist);
        self.saved_shown.store(true, Ordering::Release);
        tracing::info!(
            "m3u: saved list of source {} ({} channels, {} KB) in {} ms",
            self.id,
            channels,
            size / 1024,
            t0.elapsed().as_millis()
        );
        Some(catalog)
    }

    async fn fetch_catalog(&self) -> Result<Catalog, PortalError> {
        let t0 = Instant::now();
        let read = match &self.address {
            Address::Url(url) => match self.download(url).await {
                Ok(bytes) => {
                    let cache = self.cache.clone();
                    let check_saved = self.saved_shown.load(Ordering::Acquire);
                    tokio::task::spawn_blocking(move || read_download(bytes, &cache, check_saved))
                        .await
                        .unwrap_or_else(|e| Err(reader_lost(e)))
                }
                Err(e) => Err(e),
            },
            Address::File(path) => {
                let path = path.clone();
                tokio::task::spawn_blocking(move || read_file(&path))
                    .await
                    .unwrap_or_else(|e| Err(reader_lost(e)))
            }
        };
        match read {
            Ok((playlist, size)) => {
                let channels = playlist.live.len();
                let catalog = self.install(playlist);
                tracing::info!(
                    "m3u: list of source {} read ({} channels, {} KB) in {} ms",
                    self.id,
                    channels,
                    size / 1024,
                    t0.elapsed().as_millis()
                );
                Ok(catalog)
            }
            Err(PortalError::Unchanged) => {
                tracing::info!("m3u: list of source {} unchanged", self.id);
                Err(PortalError::Unchanged)
            }
            Err(e) => {
                tracing::warn!("m3u: list of source {} not read: {}", self.id, e);
                Err(e)
            }
        }
    }

    async fn fetch_epg(&self, _stream_id: i64) -> Result<Epg, PortalError> {
        Ok(Epg::new(Vec::new()))
    }

    async fn fetch_day_epg(&self, _stream_id: i64) -> Result<Epg, PortalError> {
        Ok(Epg::new(Vec::new()))
    }

    async fn fetch_series_episodes(&self, _series_id: i64) -> Result<Vec<Episode>, PortalError> {
        Ok(Vec::new())
    }

    fn live_stream_url(&self, stream_id: i64) -> String {
        self.lookup
            .read()
            .streams
            .get(&stream_id)
            .map(|s| s.url.clone())
            .unwrap_or_default()
    }

    fn live_stream_id(&self, url: &str) -> Option<i64> {
        self.lookup
            .read()
            .streams
            .iter()
            .find(|(_, s)| s.url == url)
            .map(|(id, _)| *id)
    }

    fn movie_stream_url(&self, _stream_id: i64, _container_ext: &str) -> String {
        String::new()
    }

    fn series_stream_url(&self, _episode_id: &str, _container_ext: &str) -> String {
        String::new()
    }

    fn catchup_url(
        &self,
        _stream_id: i64,
        _start: chrono::DateTime<chrono::Utc>,
        _duration_min: u32,
    ) -> String {
        String::new()
    }
}
```

```rust
/// The `loadfile` command for `url`. A URL that carries headers
/// (`url|User-Agent=…`, see `m3u::split_headers`) hands them to mpv as options
/// of this one file: mpv sets them for its playback and puts the defaults back
/// after it, so the next load goes without. `-1` is the playlist index that
/// mpv 0.38 put before the options; it means none.
pub fn loadfile_args(url: &str) -> Vec<String> {
    let (target, headers) = crate::m3u::split_headers(url);
    let mut options = Vec::new();
    if let Some(agent) = &headers.user_agent {
        options.push(format!("user-agent={}", option_value(agent)));
    }
    if let Some(referrer) = &headers.referrer {
        options.push(format!("referrer={}", option_value(referrer)));
    }
    let mut args = vec!["loadfile".to_owned(), target.to_owned()];
    if !options.is_empty() {
        args.extend(["replace".to_owned(), "-1".to_owned(), options.join(",")]);
    }
    args
}

/// An option value as mpv's `key=value,…` lists take any text, commas and
/// colons included: `%<bytes>%<value>`.
fn option_value(value: &str) -> String {
    format!("%{}%{}", value.len(), value)
}
```

```rust
    /// Runs the app on `portal` from now on: a new catalog, locked, fetched at
    /// once when `state` is usable; whatever belonged to the old one is
    /// forgotten.
    fn install_portal(
        &mut self,
        portal: Arc<dyn Portal>,
        creds: Option<XtreamCreds>,
        state: PortalState,
    ) {
        self.creds = creds;
        self.catalog = Arc::new(CatalogStore::new(portal));
        self.catalog_generation += 1;
        // Another portal: its stream ids mean other channels, so the old lists'
        // positions and the guide's per-channel data are of no use. The new
        // catalog starts locked, so the last PIN outcome no longer applies.
        self.forget_list_positions();
        // The old portal's EPG and fetches mean other channels now.
        self.epg_store.clear();
        self.epg_fetcher.reset(self.catalog.portal().clone());
        self.guide_view = GuideView::new(crate::guide::time::day_of(chrono::Utc::now()));
        self.guide_fetching = false;
        // The new portal's file is read when its catalog loads (the generation
        // changed); what the old portal's EPG left to write goes with it. So does
        // a write of the old portal's that fails later: the flag it sets is not
        // the one the new portal's store looks at.
        self.epg_cache_dirty_since = None;
        self.epg_cache_reading_since = None;
        self.epg_cache_retry_after = None;
        self.epg_cache_write_failed = Arc::new(std::sync::atomic::AtomicBool::new(false));
        self.adult_note = None;
        // Whatever waited for the old portal's catalog, or was told by it, means
        // nothing to the new one: a 0.5 resume would play the old portal's URL
        // through it, an old stream id would be another channel.
        self.pending_resume = None;
        self.current_stream_id = None;
        self.playing_resumed = false;
        self.catalog_noted = true;
        self.portal_state = state;
        if state == PortalState::Configured {
            self.catalog.spawn_fetch();
        }
    }

    /// Source `id`'s favorites, presets and last channel from now on. What
    /// plays is the other source's: it stops, and this source's last channel
    /// resumes, as at a start.
    fn use_data_of(&mut self, id: SourceId) {
        self.storage.set_source(id);
        self.favorites = Favorites::load(&self.storage.favorites_path()).unwrap_or_default();
        self.presets = Presets::load(&self.storage.presets_path()).unwrap_or_default();
        self.stop_playback();
        // The resumed stream gets the new catalog's first word, as at a start.
        self.catalog_noted = false;
        if let Some(lw) = LastWatched::load(&self.storage.last_watched_path()) {
            self.resume(lw);
        }
    }

    /// The name a source is saved under: none when it is its kind's default
    /// in the UI language (it then shows in whichever language is chosen).
    fn stored_name(&self, kind: SourceKind, name: &str) -> String {
        let name = name.trim();
        if name == kind.default_name(self.lang) {
            String::new()
        } else {
            name.to_owned()
        }
    }

    /// Whether a save of `editing`, kept as source `id`, puts that source in
    /// use: the command line's portal always did (Save in 0.6.1 kept and used
    /// it); a saved source when it is the one in use; a new one when nothing
    /// usable is in use.
    fn save_activates(&self, editing: Editing, id: SourceId) -> bool {
        match editing {
            Editing::CommandLine => true,
            Editing::Saved(_) => {
                !self.creds_from_command_line && self.sources.active_id() == Some(id)
            }
            Editing::New => {
                !self.creds_from_command_line
                    && (self.sources.active_id().is_none()
                        || self.portal_state != PortalState::Configured)
            }
        }
    }

    /// Writes `sources` to the ini; on failure says so in a toast and gives the
    /// state to show in place of a test's verdict.
    fn write_sources(&mut self, sources: &Sources) -> Result<(), ConnState> {
        let path = crate::args::ini_path();
        sources.save(&path).map_err(|e| {
            let (path, error) = (path.display().to_string(), e.to_string());
            self.set_toast(self.tr(T::CannotWrite, &[&path, &error]));
            ConnState::WriteFailed { path, error }
        })
    }

    /// Keeps Xtream credentials that logged in, as `keep.editing` says (the
    /// setup prompt's and the command line's go into the first saved Xtream
    /// source), and uses them at once when `save_activates` says so. The ini is
    /// written first: when that fails nothing changes, and the failure comes
    /// back to show in place of the test's verdict.
    fn keep_xtream(&mut self, keep: KeepXtream) -> Result<(), ConnState> {
        let name = self.stored_name(SourceKind::Xtream, &keep.name);
        let mut sources = self.sources.clone();
        let id = sources.keep(keep.editing, SourceKind::Xtream, &name, &keep.line);
        let activate = self.save_activates(keep.editing, id);
        if activate {
            sources.set_active(id);
        }
        self.write_sources(&sources)?;
        self.sources = sources;
        if !activate {
            tracing::info!("settings: source {} saved (xtream)", id);
            let shown = self.sources.get(id).map(|s| s.display_name(self.lang));
            self.set_toast(self.tr(T::SourceSaved, &[&shown.unwrap_or_default()]));
            return Ok(());
        }
        tracing::info!(
            "settings: portal saved to {} - connecting",
            crate::args::ini_path().display()
        );
        // The new catalog starts locked, so a save locks like Lock does: asked of
        // the old catalog, the only one that knows this stream, before it goes.
        let playing_adult = self.playing_adult();
        self.creds_from_command_line = false;
        let portal: Arc<dyn Portal> = Arc::new(XtreamPortal::new(keep.creds.clone()));
        self.install_portal(portal, Some(keep.creds), PortalState::Configured);
        if self.storage.source() != id {
            self.use_data_of(id);
        } else if playing_adult {
            self.stop_playback();
        }
        self.set_toast(self.t(T::ConnectingPortal));
        Ok(())
    }

    /// A Save in the sources section. An Xtream source is tested first and
    /// kept only if it logs in; an M3U source is kept as it is.
    fn save_source(&mut self, draft: SourceDraft) {
        match draft.kind {
            SourceKind::Xtream => {
                self.start_conn_check(draft.address, Some((draft.editing, draft.name)))
            }
            SourceKind::M3u => {
                // The command line's portal is an Xtream one: a list saved from
                // its form is a new source.

                    Editing::CommandLine => Editing::New,
                    other => other,
                };
                self.save_m3u(SourceDraft { editing, ..draft });

        }
    }

    /// its list is read again, and a changed address drops the old one's
    /// saved list.
    fn save_m3u(&mut self, draft: SourceDraft) {
        let name = self.stored_name(SourceKind::M3u, &draft.name);
        let old_address = match draft.editing {
            Editing::Saved(id) => self.sources.get(id).map(|s| s.address.clone()),
            _ => None,
        };
        let mut sources = self.sources.clone();
        let id = sources.keep(draft.editing, SourceKind::M3u, &name, &draft.address);
        let activate = self.save_activates(draft.editing, id);
        if activate {
            sources.set_active(id);
        }
        if self.write_sources(&sources).is_err() {
            return;
        }
        self.sources = sources;
        tracing::info!("settings: source {} saved (m3u)", id);
        let Some(source) = self.sources.get(id).cloned() else {
            return;
        };
        if old_address.is_some_and(|old| old != source.address) {
            let _ = std::fs::remove_file(self.storage.m3u_cache_path(id));
        }
        self.set_toast(self.tr(T::SourceSaved, &[&source.display_name(self.lang)]));
        if activate {
            let data_changed = self.storage.source() != id;
            self.creds_from_command_line = false;
            let opened = open_source(&source, &self.storage);
            self.install_portal(opened.portal, opened.creds, opened.state);
            if data_changed {
                self.use_data_of(id);
            }
        }
    }

    /// Puts saved source `id` in use, as a start on it would: its portal, its
    /// favorites and presets, its last channel. The ini says so for the next
    /// start; when it cannot be written the switch holds for this run.
    fn activate_source(&mut self, id: SourceId) {
        let Some(source) = self.sources.get(id).cloned() else {
            return;
        };
        let mut sources = self.sources.clone();
        sources.set_active(id);
        let written = self.write_sources(&sources);
        self.sources = sources;
        self.creds_from_command_line = false;
        tracing::info!("source: active {} ({})", id, source.kind.code());
        let opened = open_source(&source, &self.storage);
        self.install_portal(opened.portal, opened.creds, opened.state);
        self.use_data_of(id);
        if written.is_ok() {
            self.set_toast(self.tr(T::SourceInUse, &[&source.display_name(self.lang)]));
        }
    }

    /// Removes saved source `id`, with its favorites, presets, last channel and
    /// saved list. Never the source in use (the settings offer no Delete for
    /// it), and never the files whose data is in use (the command line's
    /// portal uses source 1's).
    fn delete_source(&mut self, id: SourceId) {
        if !self.creds_from_command_line && self.sources.active_id() == Some(id) {
            tracing::warn!("settings: source {} is in use - not deleted", id);
            return;
        }
        let mut sources = self.sources.clone();
        let Some(gone) = sources.remove(id) else {
            return;
        };
        if self.write_sources(&sources).is_err() {
            return;
        }
        self.sources = sources;
        let files = if self.storage.source() == id {
            0
        } else {
            self.storage.remove_source_files(id)
        };
        tracing::info!("settings: source {} deleted ({} files)", id, files);
        self.set_toast(self.tr(T::SourceDeleted, &[&gone.display_name(self.lang)]));
    }
```

```rust
/// The Sources section's form while the overlay is open: the source it shows,
/// and what is typed in it.
#[derive(Debug, Clone)]
struct SourceForm {
    editing: Editing,
    kind: SourceKind,
    name: String,
    /// The Xtream fields.
    portal: PortalForm,
    /// The M3U list's URL or file.
    address: String,
    /// Why the last Save went nowhere: no name, no usable address.
    problem: Option<T>,
    /// The M3U address is an Xtream portal's link: the credentials line the
    /// question offers to save as an Xtream source instead.
    xtream_offer: Option<String>,
    /// Delete was pressed once; the second press deletes.
    confirm_delete: bool,
    /// The keyboard goes to the form's first control next frame (the kind of a
    /// new source, else the name).
    focus_form: bool,
    /// The keyboard goes to the server or address field next frame.
    focus_address: bool,
}

/// What the Sources section shows the next time it draws.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum NextForm {
    Source(Editing),
    /// A new M3U list, the keyboard in its address field.
    NewList,
}

impl SourceForm {
    /// An empty form for `editing`, named after its kind's default.
    fn blank(editing: Editing, kind: SourceKind, lang: Lang) -> Self {
        SourceForm {
            editing,
            kind,
            name: kind.default_name(lang).to_owned(),
            portal: PortalForm::default(),
            address: String::new(),
            problem: None,
            xtream_offer: None,
            confirm_delete: false,
            focus_form: false,
            focus_address: false,
        }
    }

    /// The form of what `editing` names, as the view has it. A saved source
    /// that is gone gives a new one.
    fn of(editing: Editing, view: &SettingsView) -> Self {
        let lang = view.lang;
        match editing {
            Editing::New => Self::blank(Editing::New, SourceKind::Xtream, lang),
            Editing::CommandLine => SourceForm {
                portal: view.creds.map(PortalForm::of_creds).unwrap_or_default(),
                ..Self::blank(Editing::CommandLine, SourceKind::Xtream, lang)
            },
            Editing::Saved(id) => match view.sources.get(id) {
                Some(s) => {
                    let mut form = Self::blank(editing, s.kind, lang);
                    form.name = s.display_name(lang);
                    match s.kind {
                        SourceKind::Xtream => form.portal = PortalForm::of_line(&s.address),
                        SourceKind::M3u => form.address = s.address.clone(),
                    }
                    form
                }
                None => Self::blank(Editing::New, SourceKind::Xtream, lang),
            },
        }
    }

    /// The form the section opens with: the portal of `--xtream` when it runs,
    /// else the source in use, else the first saved one, else a new one,
    /// filled in from the credentials in use if there are any.
    fn first(view: &SettingsView) -> Self {
        if view.creds_from_command_line {
            return Self::of(Editing::CommandLine, view);
        }
        let saved = view
            .active_source
            .filter(|id| view.sources.get(*id).is_some())
            .or_else(|| view.sources.list().first().map(|s| s.id));
        match saved {
            Some(id) => Self::of(Editing::Saved(id), view),
            None => SourceForm {
                portal: view.creds.map(PortalForm::of_creds).unwrap_or_default(),
                ..Self::blank(Editing::New, SourceKind::Xtream, view.lang)
            },
        }
    }

    /// What Save hands the app, or why it cannot: no name, or for a list an
    /// address that is no http(s) URL or file that exists.
    fn draft(&self) -> Result<SourceDraft, T> {
        let name = without_newlines(&self.name).trim().to_owned();
        if name.is_empty() {
            return Err(T::SourceNameMissing);
        }
        let address = match self.kind {
            SourceKind::Xtream => {
                credentials_line(&self.portal.user, &self.portal.pass, &self.portal.host)
            }
            SourceKind::M3u => {
                let address = without_newlines(&self.address).trim().to_owned();
                if !is_web_address(&address) && !std::path::Path::new(&address).is_file() {
                    return Err(T::SourceAddressInvalid);
                }
                address
            }
        };
        Ok(SourceDraft {
            editing: self.editing,
            kind: self.kind,
            name,
            address,
        })
    }

    /// Save: the draft, or why not. On a list whose address is an Xtream
    /// portal's link the question comes first.
    fn save(&mut self, actions: &mut Vec<SettingsAction>) {
        self.problem = None;
        if self.kind == SourceKind::M3u {
            if let Some(line) = crate::m3u::xtream_link(&self.address) {
                self.xtream_offer = Some(line);
                return;
            }
        }
        self.push_draft(actions);
    }

    fn push_draft(&mut self, actions: &mut Vec<SettingsAction>) {
        match self.draft() {
            Ok(draft) => actions.push(SettingsAction::SaveSource(draft)),
            Err(problem) => self.problem = Some(problem),
        }
    }
}
```
